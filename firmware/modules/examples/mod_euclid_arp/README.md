# Euclid Arp (example, SDK v0.2)

Generative/control example: Euclidean 16-step arp pattern + deterministic
velocity (seed → hash), output as step/velocity arrays for the sequencer.
Parameters: EUCLID, SEED, ARP MODE, ARP RATE.

Build/check: `python3 firmware/tools/package_module.py firmware/modules/examples/mod_euclid_arp --check`
