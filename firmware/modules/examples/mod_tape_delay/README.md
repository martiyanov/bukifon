# Tape Delay (example, SDK v0.2)

Audio effect example for Bukifon Module SDK v0.2. A feedback tape-style delay
with mix control; the host model is `model.hpp` (no allocation in process).
Parameters: TIME, FEEDBACK, MIX.

Build/check: `python3 firmware/tools/package_module.py firmware/modules/examples/mod_tape_delay --check`
