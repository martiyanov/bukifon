# Архив старых версий

Здесь лежат **замороженные** артефакты прошлых ревизий. Они сохранены для истории и
сравнения, но **не являются текущими**. Текущее — в `spec/`, `renders/templates/`,
`mechanical/stl_v05_*`, `hardware/*2/` и `docs/`.

Правило: при выпуске новой версии устаревшие раскладки, STL, превью и шаблоны
переносятся сюда через `git mv` (скрипт `tools/archive_versions.sh`), чтобы в рабочих
папках не смешивались версии. `STRUCTURE.md` в корне — карта текущего.

| Папка | Версия | Что внутри | Заменено на |
|---|---|---|---|
| `v1.0/` | v1.0 (315×145) | корпус 315×145×48 (STL/preview/test_fit), старые рендеры панелей 315×145, RP2040 UF2/ELF | панель v0.4 + корпус v0.5-B |
| `v0.3/` | v0.3 handoff | JSON/DXF/SVG-раскладка от заказчика, PDF/рендеры v0.3 | `spec/panel-spec-v0.4.json` |
| `v0.4/` | v0.4 flat | STL/preview плоского корпуса (панель v0.4 остаётся текущей геометрией) | корпус v0.5-B / B-light |
| `v1.4/`, `v1.5/`, `v1.6/` | 340×185 / 380×210 / трассировка | старые шаблоны панели и spec JSON | panel-spec-v0.4 |
| `v1.7/`, `v1.8/` | 380×210 концепт | STL/preview/steps/фит-чеки v1.7/v1.8, шаблоны | корпус v0.5-B, spec v0.4 |

## Как достать артефакт

```bash
git log --oneline -- archive/v1.7/            # история файлов
ls archive/v1.7/mechanical/stl_v17/           # сами файлы
git show <tag>:path/to/file > /tmp/file       # достать версию из тега
```

Теги: `v0.1.0 … v0.11.0` — см. `CHANGELOG.md`.
