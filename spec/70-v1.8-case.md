# Букифон v1.8 — панель и корпус по handoff v0.3

Дата: 05.11.2026 (сессия ZCode). Предыдущие: v1.4.1 (340×185), v1.5 (380×210,
наклон), v1.7 (наклон снят по эталону).

## 1. Источник геометрии — handoff заказчика v0.3

`refs/v03_handoff/bukifon_layout_v03.json` — единственный источник раскладки
(фото-реконструкция, точность центров клавиш ±1–2 мм). Нормализованная копия:
`spec/panel-spec-v1.8.json`. Система координат: X вправо, Y вниз от верхней
(задней) кромки, угол + по часовой на виде сверху, поворот колпачка вокруг
его центра. Половины клавиатур НЕ поворачиваются как блок — углы уже в клавишах.

Ключевое отличие от v1.5/v1.7: экран опущен (центр Y 61.4, вырез Y 29…94.2),
джеки на Y 11, энкодеры Y 30.5/57.5, фейдеры — пазы 2.5×63 на (180/200, 149),
клавиши — «веер» с углами ±8…44°.

## 2. Панель

- 380 × 210 × 3 мм, 3 печатные детали (стол 220 мм):
  - **panel_C «шапка»**: X 131.2…249.1, Y 0…98 (джеки + экран);
  - **panel_L**: X 0…131.2 сверху + X 0…190 ниже Y 98 (Т-образная);
  - **panel_R**: зеркально.
- Швы: X 131.2 (Y 0…98), горизонталь Y 98 (X 131.2…249.1), X 190 (Y 98…210),
  X 249.1 (Y 0…98). Зазоры до окон/гаек ≥ 1.75 мм (гайка джека Ø10 + 1).
  Шов X 190 внизу проходит между пазами фейдеров (запас 7.25 мм).
- Соединение швов: 10 штифтов Ø3.2 (см. DOWELS в `tools/v1_8_case.py`) + клей.
- Крепление: 8 × M3 × 8 потай в стойки с термовтулками, координаты стоек
  PANEL_POSTS; штифты и цековки — в `tools/v1_8_case.py`.
- Окна клавиш = колпачок + 1.0 мм (19.5 × 18.5, углы по v0.3) — **макетные**:
  финальные окна под Choc по KiCad Lapka-42 (см. §6).

## 3. Z-стек корпуса (полная высота 63 мм)

| Z | что |
|---|---|
| −3…0 | ножки Ø10×3 (4 шт.) |
| 0…3 | дно (PETG 3 мм) |
| 3…57 | полость (стенки 2.4), электроника |
| 57…60 | панель 3 мм |

Стойки (пол→верх): панель 8×M3 → 57; рамка экрана 4×M2.5 → 46.5; деки 8×M2.5
(провизор) → 50.4; фейдеры 4×M2.5 → 44; PANEL-1 rev.2 6×M3 (провизор) → 48;
CORE-1 rev.3 4×M3 (провизор) → 20. Скорлупа: 2 половины, шов X 190,
5 шипов 8×3 + клей. Вентиляция: 24 паза 4×16. Задняя стенка: провизор
(USB-C, DC, выкл., 2×MIDI DIN, 2×IDC-26 шина, reset).

## 5. Решение по экрану

Плата Waveshare 5″(B) 121.1×87.1 **задевает угол окна клавиши L_K04/R_K04**
(верх колпачка пересекается с модулем по Z). Поэтому: голое стекло 5″
(активная область 108×64.8 = вырез) прижимается рамкой `screen_carrier`
132×87×2.5 к тылу панели (стекло 53.9…57, пена-компенсатор), драйвер —
на PANEL-1 rev.2 (как в плане электронки §8 handoff). Зазор клавиш до
конверта стекла = 3.9 мм ✓ (совпадает с handoff).

## 6. Провизор (до производства)

1. **Клавиши**: координаты/углы — фото-реконструкция ±1–2 мм. Перед печатью
   финальной панели — импорт `Lapka42.kicad_pcb` (footprint SW_Choc_V1V2_HS),
   пересчёт окон и стоек дек. Текущие окна = колпачок + 1 мм.
2. **Стойки дек/PANEL-1/CORE/фейдеров** — эскизные, подгонка под rev.3/rev.2.
3. **Паз фейдера** 2.5×63 — проверить с образцом RS60N11 (лопасть 1.2–1.5 мм).
4. **Задняя стенка** — набор окон провизорный до CORE-1 rev.3.
