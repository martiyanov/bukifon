# Реестр требований Букифона (единственный источник истины)

Причина появления: в репозитории одновременно жили три разных описания железа
(315×145/8 ручек/2.8″ против 380×210/16 ручек/5″, плюс старые цифры в README и
firmware/README). Этот файл фиксирует актуальные требования; всё, что противоречит
ему — устарело и должно быть исправлено или удалено.

Статус: **черновик на подпись** (см. раздел «Подпись»).
Дата: 05.11.2025.
