# Реестр требований Букифона (единственный источник истины)

Причина появления: в репозитории одновременно жили три разных описания железа
(315×145/8 ручек/2.8″ против 380×210/16 ручек/5″, плюс старые цифры в README и
firmware/README). Этот файл фиксирует актуальные требования; всё, что противоречит
ему — устарело и должно быть исправлено или удалено.

Статус: **черновик на подпись** (см. раздел «Подпись»).
Дата: 05.11.2025.

| ID | Требование | Значение | Статус |
|---|---|---|---|
| R-01 | Форм-фактор | настольный, 380 × 210 × 63 мм | ✅ закрыто |
| R-02 | Панель | 380 × 210 × 3 мм, PETG, без динамиков, без джеков под экраном | ✅ закрыто |

## 4. Журнал решений

| # | Дата | Решение | Основание |
|---|---|---|---|
| D-01 | 05.11 | панель 380×210 (а не 340×185) | при ±18–22° две Lapka + фейдеры не влезают в 185 |
| D-02 | 05.11 | клавиши — точная Lapka-42, половины ±18° | концепт нарисован «на глаз» (RMS 7.5 мм) |
| D-03 | 05.11 | 10 джеков сверху, без джеков под экраном | ТЗ заказчика |
| D-04 | 05.11 | нет динамиков | ТЗ заказчика |
| D-05 | 05.11 | платформа = сэмплер + синтез + модули сообщества | требование заказчика |
| D-06 | 05.11 | первый этап — бенчмарк, не rev.3 | ревью `docs/03-second-opinion-mcu.md` |
| D-07 | 05.11 | ESP32-P4 — основной кандидат (после бенчмарка) | USB HS + DSI + 32 МБ PSRAM |
