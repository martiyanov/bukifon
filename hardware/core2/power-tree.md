# CORE-2 — дерево питания и бюджеты токов

> **STATUS: PRE-FREEZE / DO NOT FABRICATE.** Расчёты — оценочные, для
> проверки архитектуры до бенчмарка; не являются финальным thermal/PDN-анализом.

## 1. Топология

```
USB-C (5 V, данные+заряд) -> USBLC6-2SC6 -> F1 polyfuse 1.5 A -> BQ24074 (1.5 A charger,
    power-path) -> VSYS (3.0..4.4 V) / charge 1S2P 18650 via BMS (BQ297xy + 2x N-MOS)

VSYS --+-- U1 MT3608 boost --> +12 V (12.1 V) --+--> BUS1/BUS2 (IDC-26, protected)
       |                                        +--> U5 MC34063 inverter --> -12 V
       +-- U2 MT3608 boost --> +5 V (5.1 V) ---+--> WS2812 chain / audio / relays
                                                +--> U3 AP2112K-3.3 --> +3V3 (periph/analog)
                                                +--> U6 AP2112K-3.3 --> +3V3_C6 (ESP32-C6)
                                                +--> U4 MP1584 buck -> +3V3_MCU (P4+PSRAM)
                                                +--> U7 MT3608 boost #3 --> BL_20 V

AGND / DGND / PGND — три отдельные цепи, соединены в одной точке NT1/NT2 (net-tie).
LDO/DC-DC входы и выходы развязаны ферритами FB1..FB6 + 100 nF/10 uF.
C6 — сопроцессор Wi-Fi 6 / BLE 5.3 (ESP32-C6-MINI-1) с отдельным LDO +3V3_C6,
чтобы импульсные токи радио (до 240 мА) не просаживали +3V3 и +3V3_MCU.
BL_20 V — boost MT3608 #3 для линейки подсветки LCD (19–22 В, 20-25 мА),
на PANEL-2 идут только BL_ANODE / BL_CATHODE / BL_PWM.
```

## 3. Расчёт токов

**+5 В (MT3608 #2, 2 A switch).** Бюджет 1000 мА (WS2812 550 мА при прошивочном
лимите яркости + BL-boost вход 80 мА + C6 LDO 60 мА + аудио/MIDI/логика 310 мА).
Входной ток буста с VSYS=3.7 В: `Iin = 5.1*1.0/(0.88*3.7) = 1.57 А` — 
78 % от предела 2 А. Без прошивочного лимита 74×WS2812 на полной яркости = 4.4 А —
поэтому **аппаратный polyfuse 2.5 А + firmware cap обязательны**.

**+12 В (MT3608 #1).** `Iin = 12.1*0.33/(0.85*3.7) = 1.27 А` (63 % от 2 А).
Рельс идёт на 2 порта шины (2×60 мА), ОУ ±12 В (30 мА) и вход MC34063 (~120 мА).

**−12 В (MC34063).** 95 мА из 250 мА; вход по +12 В ≈ 120 мА; КПД ≈75 %%.

**+3V3 (AP2112K).** 150 мА из 450 мА (LDO 600 мА, derating 75 %%).

**+3V3_MCU (MP1584).** 700 мА из 2400 мА (3 А × 0.8); отдельный LDO/DC-DC
для MCU+PSRAM — предотвращает просадки при пиках P4/PSRAM и SD-записи.

**Батарея/VSYS.** Суммарная мощность worst-case:
`P = 12.1*0.33/0.85 + 5.1*1.0/0.88 = 10.5 Вт` → `Ibat = 2.84 А` при 3.7 В.
1S2P 5 А·ч → ~0.58 C, BMS FET ≥5 А; типичное потребление 2–4 Вт → 3–5 ч работы.

## 4. Power-path и зарядка

| Сценарий | Путь | Поведение |
|---|---|---|
| Только USB-C | VBUS → BQ24074 → VSYS → бусты | Система работает; батарея заряжается (если есть) |
| USB + батарея | BQ24074 power-path | Нагрузка питается от VBUS, излишек идёт в заряд; разряда нет |
| Только батарея | BMS → VSYS → бусты | Штатная работа; BMS отсекает 2.8 В |
| Нет питания | BMS deep-discharge | Отключение; P4 CHIP_PU = 0 через 100k PD |

BQ24074 выбран вместо TP4056: встроенный power-path (не разряжает батарею при USB),
DPPM, ILIM/ISET/ITERM/TMR, вход до 6.5 В. Заряд 1 А (ILIM 1.5 А, ISET 1.5 к).

## 5. Пусковые токи и защита

| Что | Решение |
|---|---|
| Inrush USB-C | polyfuse 1.5 А + BQ24074 soft-start/ILIM; X2 10 uF + 100 uF на VBUS |
| Hot-plug батареи | 100 uF + TVS + BMS; феррит на входе MT3608 |
| Пуск MT3608 | внутренний soft-start, C_out 220 uF + 22 uF керамика |
| КЗ на шине | на каждый порт: polyfuse 0.5 А (+12 В), polyfuse 0.3 А (−12 В), SS34 (переполюсовка) |
| Просадка 3.3 В при SD/PSRAM | отдельный +3V3_MCU, 2×10 uF + 6×100 nF у модуля |
| Brownout P4 | внутр. BOD + RC 10 k/100 nF на CHIP_PU + супервизор не нужен (pre-freeze) |
| Watchdog | RTC WDT в прошивке (2 s), сброс CHIP_PU через GPIO expander не требуется |

## 7. Что проверить до заказа плат (PRE-FREEZE gate)

1. Бенчмарк P4: реальный ток 3V3_MCU и +5V при 800×480 RGB + SD-записи (осциллограф, 20 МГц полоса).
2. Тепловой режим MT3608 #2 при 1.0 А/5 В 30 мин (корпус модуля ≤ 80 °C).
3. Inrush USB-C при подключении (токовый пробник; не должен срабатывать polyfuse).
4. Проверить BQ24074 power-path при одновременной зарядке и пиковой нагрузке (DPPM).
5. Замерить шум −12 В MC34063 (< 50 мВ p-p) — иначе LDO/LC-фильтр на аналог.
6. Уточнить тепловой бюджет 1S2P при 2.9 А разряда (пакет 2×18650).
