# CORE-2 (P4) — DFM / testability (до разводки PCB)

> **STATUS: PRE-FREEZE / DO NOT FABRICATE.** Документ фиксирует требования к тестопригодности,
> серийному номеру, recovery и DFM **до** разводки CORE-2 rev.2 (P4-ветка — главная).
> Основание: `docs/36-rc-definition.md` §2 (критерии приёмки) и §4.4 (DFM до разводки),
> `docs/38-dfm-testability.md`. Платы не заказывать до P1-стенда и подписи реестра.

## 3. Serialization / traceability

На CORE-2 есть **24C32 (U41, I2C 0x57, 4 КБ)** — используем как основной носитель:
| Offset | Поле | Формат |
|---|---|---|
| 0x000 | magic `BFSN` + версия карты | 4+1 байт |
| 0x008 | SN (10 символов, base32) | 10 байт |
| 0x018 | ревизия платы (rev.2 = 0x02) | 1 байт |
| 0x019 | дата сборки (YYMMDD) | 3 байт |
| 0x01C | batch id | 2 байт |
| 0x020 | калибровка CV DAC (offset/gain ×8 каналов) | 32 байт |
| 0x040 | калибровка AUDIO (bias/уровень) | 16 байт |
| 0x100 | лог производства (тест/оператор/дата) | 64 байт |

Fallback: OTP/eFuse P4 или защищённая flash-зона `nvs` + копия в 24C32; QR/DataMatrix на
корпусе (SN+rev), дублируется на наклейке платы (не под разъёмом). Прошивка читает SN через
I2C при boot, пишет в USB-дескриптор (iSerial) и лог.

## 4. Recovery / bootloader

- **P4 ROM download:** UART0 (J4: GND/TX/RX) + BOOT (GPIO35=0, GPIO36=1 для joint download);
  `esptool`/`idf.py flash`; BOOT-кнопка SW1 и RESET SW2 на плате.
- **USB:** P4 ROM не имеет USB-DFU как S3; recovery — через UART0; в приложении — CDC/DFU-класс
  (esp_tinyusb) для обновления без кнопок; проверить на P1 (открытый пункт).
- **Partition table:** factory + ota_0 + ota_1 + otadata + nvs; `esp_ota_mark_app_valid` rollback;
  safe mode: 3 неудачных boot → factory + подсветка ошибки; watchdog.
- **Что добавить на PCB сейчас:** BOOT/RESET кнопки (есть), UART0 TP J4 (есть), тестпады
  GPIO35/GPIO36, индикатор питания/заряда (есть LED CHG), 2-пин recovery jumper (BOOT→GND) —
  опционально; отдельный JTAG-разъём не нужен (P4 JTAG — через UART0/USB на P1 проверить).
- **Битая прошивка:** ROM не стартует app → UART0 download; OTA rollback; SD/USB hot-remove
  не повреждает проект (журнал/резерв, docs/36 тест 5).

## 5. DFM (CORE-2 rev.2)

- **Стек:** 6 слоёв (RGB/HS USB/DSI), 1.6 мм FR4, 1 oz; min trace/space 0.10/0.10 мм, via 0.2/0.45.
- **Импедансы:** USB HS 90 Ω differential (TP11/12), SDIO 50 Ω, RGB PCLK/data — согласование,
  длина PCLK/DE к FPC ≤40 мм; I2S — экранировать/короткие.
- **FPC-40 (J15):** ориентация pin1 (треугольник), ключ/стоппер, stiffener; под шлейфом нет
  меди/TP; ground fingers; фиксация после сборки.
- **Разъёмы J14/J15/J16/J17/J18:** шелкография pin1/направление, ключ IDC, ответные вилки;
  J17/J18 — силовые пары PGND, при 3 А — альтернатива Micro-Fit 3.0 (O-11).
- **Крепёж:** 6×M3 (3.2 мм отверстия, keepout Ø6 мм, без меди/TP под головкой), стойки корпуса
  docs/21; высота под FPC/шлейфы.
- **Панелизация:** 2×2 (или 4×1) с рельсами 5 мм, tooling holes, fiducials 3×1 мм, V-score только
  прямые края; зазоры между платами ≥2 мм.
- **Зазоры:** 20 В BL ≥0.5 мм (лучше 2 мм), HV-зона маркировать; AGND/DGND/PGND — звезда NT1/NT2,
  stitching via; C6 antenna keepout ≥15 мм без меди/шелкографии.
- **Шелкография:** `CORE-2 rev.2`, pin1 всех разъёмов, полярность диодов/электролитов/LED,
  SN/QR-зона, TP-подписи, предупреждение о 20 В; не ставить шелкографию под FPC.
- **TP/пады:** не под разъёмами и не в зоне шлейфов, доступ после сборки, маска открыта.
- **ESD/защита:** USBLC6, TVS на входы/джеках, polyfuse; проверка после сборки.
