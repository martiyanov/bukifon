## 2. Схема соединений

```
        ┌──────────────── M1: имитатор батареи ────────────────┐
        │  ЛБП 0…5 В / 5 А  +  0.1 Ω / 5 Вт (Ri = 1S2P)       │
        └───────────────────────┬─────────────────────────────┘
                                │ PACK+ ── F1 5 А ──┐
                          ┌─────┴──────┐           │
                          │ M2: BMS 1S │  P+ = VBAT│
                          └─────┬──────┘           │
                                │ VBAT             │
        ┌───────────────────────┴──────────────────┴──────────────────────┐
        │ M3: BQ24074EVM   USB 5 В / 1.5 А → IN,  OUT = VSYS,  BAT = VBAT  │
        └───────────────────────────────┬─────────────────────────────────┘
                                        │ VSYS  (INA226#1: шунт 5 мОм)
     ┌──────────────┬───────────────────┼────────────────────┬───────────────────┐
     ▼              ▼                   ▼                    ▼                   ▼
 [M4 +12 В]     [M5 +5 В]         [M6 −12 В IBB]        [M12 +3.3 В]        [M8 master sw]
 TPS61088EVM    TPS61088EVM       LMR33630EVM (IBB)     TPS63802EVM        2×AO3401A
     │              │                   │                    │                   │
  D7 SS34         π-фильтр           D8 SS34             (справочно)        от VSYS → VSYS_SW
     │              │                   │                                           │
  π-фильтр       INA226#3           π-фильтр                                    M7: LED-ключ
     │              │                   │                                           │
 INA226#2      нагрузка 3.2 Ω      нагрузка 126 Ω                          5V_LED → 9.1 Ω → PGND
 (+12 В)          (1.6 А)             (95 мА)                                  (550 мА, эмул. WS2812)
     │              │                   │
  нагрузка       5V_LED ветвь       PGND (возврат −12 В — только PGND)
  36 Ω/5 Вт
  (330 мА)

 M9: MAX17048 EVKIT — VDD ← VBAT (Kelvin), GND = PGND, SDA/SCL → USB-I2C (0x36), ALRT → лог
 M10: INA226 ×2–3 → USB-I2C (0x40/0x41/0x44); DMM V на B2/B3/B4; осц. на B2/B3/B4; термопары
```

**Ключевые связи (не путать):**
- **VSYS → boost +12 → (D7) → +12**; **VSYS → IBB −12** (GND микросхемы IBB = −12 В!);
  **VSYS → +5** (и опционально **VSYS → TPS63802 → +3.3** для CORE-S3);
- **заряд:** USB 5 В → BQ24074 IN; BQ24074 OUT = VSYS; BQ24074 BAT = VBAT (P+ после BMS);
- **5V_LED:** +5 В → F5 2.5 А → 5V_LED → низковольтный ключ AO3400A → LED_RET → PGND;
- **PGND** — одна силовая земля стенда; у IBB она же «выход buck» (см. docs/44 T5).

## 4. Правила проводки (обязательны)

1. **Только пайка**: EVM, сверлёные платы, мини-PCB. **Breadboard и Dupont-«сопли» запрещены**
   (D-76): контактные потери и шум несопоставимы с платой.
2. **Витая пара** для силовых пар (supply+return): VSYS, +12 В, −12 В, +5 В, 5V_LED.
   Провод **20 AWG** (до 3 А), длина ≤15 см.
3. **Kelvin-сенс** — отдельные тонкие провода (26–28 AWG) прямо к выводам выходного
   конденсатора; шунт INA226 — 4-проводно.
4. **Ripple**: 1× пробник с пружиной земли на конденсаторе; для −12 В — дифференциально
   (земля осциллографа **не** подключается к −12 В).
5. Силовые петли — минимальной площади; входные конденсаторы EVM/мини-платы — максимально
   близко к ИС (это то, что нельзя воспроизвести на макете — см. §5).
6. Все соединения — пайка/клеммы с натягом; никаких «скруток» в силовых путях.

## 5. Что на EVM, что на мини-плате, что нельзя проверить на EVM

| Проверяется | Где | Комментарий |
|---|---|---|
| Топология/КПД/шум/тепло преобразователей | EVM (M4–M6, M12) | нижняя оценка; финальный ripple/тепло — на PCB |
| IBB −12 В (переделка EVM) | EVM + мини-плата | перепайка ОС/земли по TI SLVA542 |
| Power-path/тепло BQ24074 | BQ24074EVM | T6 |
| EN-обвязка, master switch, LED-ключ | мини-плата (пайка) | аналогов нет на EVM |
| Разъём J3 при 3 А | реальный IDC-20 | T13 |
| **Нельзя на EVM:** | | |
| тепловой режим реальной платы 130×80 (θJA/медь/полигоны) | — | консервативная оценка + финал на PCB |
| layout-зависимый шум (горячие петли, звезда PGND, AGND) | — | T3 = нижняя оценка |
| взаимодействие с CORE-2 (PWR_GOOD/EN от MCP23017, BL/Wi-Fi/USB HS) | — | только на связке |
| ток OFF (утечки платы), EMI/ESD в корпусе, soak 24 ч | — | на PCB/собранном изделии |
| точный КПД на финальных индукторах/разводке | — | оценка ±3…5 % |

Полный список «что нельзя проверить на EVM» — `docs/44` **§7.0** (10 пунктов).

## 6. Быстрый чек-лист первого дня

1. ☐ Собрать мини-платы: IBB-обвязка (L 22 мкГн, C_in 22 мкФ/25 В, C_out 22 мкФ×2, R 110k/10k,
   C_BOOT 100 н, C_VCC 1 мкФ, D8), master switch, LED-ключ, EN-опто — **только пайка**.
2. ☐ Прозвонить: PGND↔N12 **не** КЗ; вход 25 В керамика; полярность C_out (N12 — минус).
3. ☐ Первый пуск IBB: ЛБП 3.7 В, **ограничение 0.3 А**, без нагрузки, смотреть −12 В на 126 Ω.
4. ☐ Подключить INA226 ×2–3 + USB-I2C, проверить лог 1 Гц (CSV по §5 docs/44).
5. ☐ Прогнать T1 (3×3) → затем T2/T5; на термопары — U(TPS61088), U(LMR33630), U(BQ24074), банки.
6. ☐ ES-меры: обувь/коврик; банки — только защищённые; заряд — под присмотром.

## 8. Безопасность (коротко)

- Первые тесты — **от имитатора батареи**, не от «голых» 18650; F1 5 А в плюсовом проводе — всегда.
- Ограничение тока ЛБП ≤5 А; КЗ/SCP-тесты — только с ограничением и предохранителем.
- «Земля» осциллографа **не** на −12 В (только дифф./2 канала).
- Li-ion: заряд только с NTC/TS и под присмотром; при нагреве банки >45 °C — стоп.
