## 1. Что на макет-столе

| ID | Узел | Что это физически | Что проверяет |
|---|---|---|---|
| M1 | **Имитатор батареи** | ЛБП 0…5 В/5 А + 0.1 Ω/5 Вт | все T1–T7 вместо «голых» банок |
| M2 | **Пакет** | 2 × 18650 (защищённые) в держателях + F1 5 А + BMS 1S 2P | T6, T8, T9, T10 |
| M3 | **BQ24074 breakout** | готовая плата зарядника/power-path | T6 (power-path, DPPM, тепло) |
| M4 | **+12 В** | модуль на TPS61088 + D7 SS34 + π-фильтр | T1/T2/T3/T4 |
| M5 | **+5 В** | модуль на TPS61088 + π-фильтр (+ вариант TPS63802) | T1/T2/T3/T4/T2b |
| M6 | **−12 В (IBB)** | LMR33630 на переходнике PowerPAD + L 22 мкГн + π + D8 | **T5**, T1/T2/T3/T4 |
| M7 | **5V_LED** | ключ AO3400A + 9.1 Ω/5 Вт (550 мА) | T3 (сеанс B), T12 |
| M8 | **Master switch** | 2 × AO3401A + MMBT3904 | T11, T7 |
| M9 | **Гейдж** | MAX17048 breakout на Kelvin к пакету | T10 |
| M10 | **Приборы** | INA226 ×3 + USB-I2C; осциллограф; DMM 4½ ×2; термопары K | T1–T13 |
| M11 | **Разъём** | IDC-20 + шлейф (2 пина/полярность) | T13 (решение IDC vs Micro-Fit) |

## 2. Схема (сжато, полная — docs/44 §3)

```
M1 имитатор → F1 5 А → BMS → VBAT ──┬── M3 BQ24074 (USB → VSYS) ── VSYS
                                     │        INA226#1 на VSYS
                                     ├── M4 TPS61088 → D7 → π → +12 В (INA226#2) → 330 мА
                                     ├── M5 TPS61088 → π → +5 В (INA226#3) → 1.6 А ── M7 LED 550 мА
                                     └── M6 LMR33630 IBB (GND МС = −12 В) → D8 → π → −12 В → 95 мА
M9 MAX17048: VDD ← VBAT, I2C 0x36 → USB-I2C;  M8 master switch — между VSYS и потребителями
```

## 4. Быстрый чек-лист первого дня

1. ☐ Собрать IBB-макетку (§3.2 docs/44): прозвонить PGND↔N12 (**не** КЗ), вход 25 В керамика.
2. ☐ Собрать ключ LED и master switch, прозвонить.
3. ☐ Первый пуск: ЛБП 3.7 В, **ограничение 0.3 А**, без нагрузки — проверить −12 В на 126 Ω,
   затем +12 В, потом +5 В (по одному!)
4. ☐ Подключить INA226 ×3 + USB-I2C, проверить лог 1 Гц.
5. ☐ Прогнать T1 (3×3) — если OK, переходить к T2/T5.
6. ☐ Повесить термопары на U(TPS61088 #1/#2), U(LMR33630), U(BQ24074), банки.

## 6. Правила безопасности (коротко)

- первые тесты — **только от имитатора батареи**, не от банок;
- F1 5 А в плюсовом проводе пакета всегда; ограничение тока ЛБП ≤5 А;
- «земля» осциллографа **не** на −12 В (только дифф/2 канала);
- ripple мерить 1× с пружиной земли на выходном конденсаторе;
- Li-ion: заряд только с NTC/TS, не оставлять без присмотра, при нагреве > 45 °C — стоп.
