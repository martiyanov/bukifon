# hardware/modules — аналоговые модули шины Букифон

Пять сменных картриджей формата **110 × 70 мм** (плата 109 × 69 мм, 1.6 мм) под
26-контактную шину Букифон (см. `spec/20-electronics.md` §7):

| Модуль | Ядро | Что делает | Статус |
|---|---|---|---|
| **MOD-VCO-1** | AS3340 (DIP-16, Alfa) | VCO 1 В/окт, пила/квадрат/пульс, PWM, 2×CV входа, ±5 В AC | схема + BOM + ERC |
| **MOD-FILTER-1** | LM13700 (DIP-16) + TL074 | SVF 12 дБ/окт LP/BP/HP, экспоненциальный срез, резонанс | схема + BOM + ERC |
| **MOD-PROTO-1** | — | все цепи шины на гребёнках 2.54, поле 60 × 45 мм | схема + BOM + ERC |
| **MOD-LADDER-1** | AS3320 (DIP-18, Alfa) | лестничный 4-полюсный фильтр «как у Муга», LP/HP, drive | схема + BOM + ERC |
| **MOD-ENSEMBLE-1** | 2 × PT2399 + TL074 + CD4053 | ансамбль/хорус с LFO, формантный RC-фильтр, bypass | схема v0.9 + BOM + ERC |

## Как открыть и перегенерировать

```bash
# открыть в KiCad 10
open MOD-VCO-1.kicad_sch

# пересобрать схемы из кода описания
/opt/homebrew/bin/python3 gen/build.py            # все пять
/opt/homebrew/bin/python3 gen/erc.py              # ERC + сводка

# экспорт (то, что лежит в pdf/svg/net)
K=/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli
$K sch export pdf   MOD-VCO-1.kicad_sch -o pdf/MOD-VCO-1.pdf
$K sch export svg   MOD-VCO-1.kicad_sch -o svg/MOD-VCO-1
$K sch export netlist MOD-VCO-1.kicad_sch -o net/MOD-VCO-1.xml --format kicadxml
$K sch erc          MOD-VCO-1.kicad_sch -o erc/MOD-VCO-1.rpt
```

Схемы выполнены в стиле **named-net**: у каждого вывода стоит короткий вывод-провод
с именем цепи. Это обеспечивает машинно-проверяемую связность (ERC + netlist) и
читаемость на A2. Логические блоки описаны в заголовке листа и в `Calc.md`.
**Это не pictorial-разводка для «рисования глазами», а connectivity-схема** — при
переводе на плату пользоваться netlist (`net/*.xml`).

## Как подключить

1. Соберите картридж (см. `CARTRIDGE.md`), вилка IDC-26 — на длинной стороне.
2. Шлейф IDC-26 мама-мама ≤ 15 см — в любой из портов CORE-1
   (PORT0 = верхний док, PORT1 = слот A, PORT2 = слот B / нижний док).
3. Питание подаётся только с шины: +12 В / −12 В / +5 В / +3V3. **Не подавайте
   питание на картридж вне шины** — на плате нет защиты от переполюсовки
   (защита есть на CORE-1, §3).
4. Аудио: AUD_IN — вход (0…±5 В AC, от CORE-1), AUD_OUT — выход в аналоговый
   сумматор CORE-1 (нагрузка 10 кΩ). Постоянка на шину запрещена — на всех выходах
   стоят разделительные 10 µF.

## Как выбрать порт / адрес EEPROM

Адрес EEPROM = **0x50 + номер порта** (перемычки JP1…JP3, см. `Calc.md` §0):

| Порт | A2 A1 A0 | Адрес |
|---|---|---|
| PORT0 (верхний док) | 0 0 0 | 0x50 |
| PORT1 (слот A) | 0 0 1 | 0x51 |
| PORT2 (слот B / низ) | 0 1 0 | 0x52 |

Перемычка в положении 1-2 = 0, 2-3 = 1 (маркировка на шелкографии: «0» / «1»).
Дескриптор в первых 32 байтах: `kind` = 1 (VCO), 2 (FILTER), 7 (LADDER),
8 (ENSEMBLE), 0xFF (PROTO) — см. `spec/40-firmware.md`. Прошивка CORE-1 читает
EEPROM на каждом порту при старте и включает модуль в меню.

**Важно:** модуль не должен отвечать по I2C, пока CORE-1 не обратится к его адресу.
Подтяжки SDA/SCL стоят только на CORE-1 (4.7 кΩ) — на модулях их нет, чтобы не
перегружать шину.

## Сборка/монтаж

1. Пайка: сначала DIP-панельки (AS3340/AS3320/LM13700/TL074/TL072/TL431/24C02),
   затем пассивные элементы, затем IDC-26 и гребёнки PROTO-1.
2. Все конденсаторы C0G/NP0 — только там, где указано (тайминг VCO, интеграторы
   SVF, лэддер). Электролиты 10 µF — на 25 В.
3. После сборки проверить: +12/−12/+5/+3V3 без нагрузки (ток ≤ 5 мА), затем
   установить ОУ и специализированные ИС.
4. Подстройка: VCO — RV3 (шкала 1 В/окт), RV4 (ВЧ-трекинг), RV5 (±5 В на выходе).
   FILTER — RV1 (резонанс), подстроечный R19 для точного 1 В/окт.
5. Записать дескриптор в EEPROM (адрес 0x50+порт) — утилита в `firmware/` (см.
   `spec/40-firmware.md`).

## Что не сделано (честно)

- **Печатные платы не разводились** — есть только схемы, netlist, BOM и чертёж
  картриджа. Для заказа плат нужен этап layout (KiCad PCB) + DRC.
- **SPICE-моделирование не выполнялось** — все числа аналитические.
- **ENSEMBLE-1** — схема уровня v0.9 по указанию Lead: обвязка PT2399 и формантный
  каскад требуют макетирования; BBD-вариант не разведён (см. `availability.md`).
- **Самоосцилляция FILTER-1** в текущем номинале RV1 = 1 МΩ даёт Q ≈ 10 (сильный
  резонанс, но не генерация); опция — уменьшить R3 до 1 кΩ.
- **CV3/CV4**: по `spec/20` §7 это линии **module → core**, поэтому PWM/срез/резонанс
  взяты с CV1/CV2. Задание упоминало CV3/CV4 как входы — расхождение с контрактом
  зафиксировано Lead'у.
