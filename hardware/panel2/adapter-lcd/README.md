# LCD FFC-40 адаптер (HotLCD ST7262) — PRE-FREEZE bench adapter

**Не заказывать плату без ревью.** Назначение — проверить 5.0″ 800×480 RGB565 FFC-40 панель (MPN **TFT-H050A1SVIST4R40**, ST7262) на P1-стенде до PCB: повторяет pinout PANEL-2 **J12** (FFC-40, 23 сигнала) и даёт тестпоинты на все линии панели. Полная документация — [`docs/49-lcd-adapter.md`](../../../docs/49-lcd-adapter.md).

## 2. Схема в двух словах

* **J1** — вход FFC-40 (ZIF 0.5 мм), pinout = PANEL-2 J12 (rev.2, 23 сигнала: 16 RGB, PCLK/DE/HSYNC/VSYNC, BL_PWM, BL_ANODE/BL_CATHODE, LCD_3V3, GND).
* **J2** — выход FFC-40 на хвост панели (пин-аут — предположение, 0R-перемычки позволяют переназначить любую линию).
* **0R-перемычки (R1…R31)** — «pinout jumper»: P_<сигнал> ↔ J12-линия / GND / DISP_CTRL. Позволяют собрать правильный пин-аут после промера образца.
* **Тестпоинты** — 31 сигнал панели (R0-R7, G0-G7, B0-B7, PCLK, DE, HS, VS, DISP, LED_A, LED_K) + BL_PWM, +3V3, GND.
* **J3** (JST PH 2-pin) — вход внешнего boost подсветки 18…22 В / 40 мА (R34/R35); штатно подсветка идёт с CORE-2 через J12 (R30/R31).
* Габарит 120 × 76 мм, 2 слоя, крепление панели 4 × M3 (outline панели 120.7 × 75.8).

## 4. Что проверить до питания

1. Прозвонить GND (J2 3/5/30/36/39/40) и 3V3 (4/37/38) — КЗ нет.
2. Сверить пин-аут панели с даташитом (O-15): при расхождении перепаять 0R.
3. Проверить контактную сторону FFC (same/opposite) и pin 1.
4. Подсветка: не подавать 18…22 В на J12 — только J3 (R34/R35).

## 5. Открытые вопросы

* **O-15** — LCD_DISP: на PANEL-2 J12 DISP нет; на адаптере DISP подтянут к 3V3 (можно подать внешний на TP). Решение о пине J12 — после проверки образца.
* Пин-аут HotLCD — предположение, подтверждается мультиметром/даташитом образца.
* PCB (2 слоя, 120×76) не разводился: сначала заказ/проверка образцов (docs/42 §144).
