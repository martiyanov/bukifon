## Порядок заказа (4 волны)

1. **Волна 1 (день 0) — ядро P1:** A1–A6, A11, A12 (Mouser/Espressif/Ali); A7–A8 — у местных,
   если нет своих.
2. **Волна 1b (тот же день) — критические образцы:** A13a–d (дисплеи+FFC/ZIF), **B-EVM:
   LMR33630ADDAEVM-IBB → TPS61088EVM-677 → BQ24074EVM** (Mouser/TI), bare-IC B-base (Mouser),
   P-19…P-25/Ali. **Это критический путь к PCB.**
3. **Волна 2 (после проверки pinout/адаптера) — C:** JLCPCB (адаптер) + C2–C7 (LCSC/Ali).
   Можно параллельно с волной 1b, если MPN ZIF/FFC подтверждены.
4. **Волна 3 — D:** филамент/крепёж/сопло (локально/Ali) — к моменту печати.

**Не заказывать:** PCB CORE-2/PANEL-2/PWR-2 (PRE-FREEZE, до DRC/DFM и RC-DoD —
[`docs/36`](36-rc-definition.md), [`docs/42`](42-dfm-review-gpt.md)).

## Где оценки (±30 %)

- Дисплеи A13a–c и C6 (HotLCD/Ali, партии/доставка), NHD $65 — по каталогу Newhaven/DigiKey;
- A7/A8 (БП, нагрузка) — местные цены; A14 — Ali;
- B-EVM — по каталогам TI/Mouser ($45–50), MAX17048 breakout $13;
- C1 PCB (JLCPCB, зависит от панелизации/доставки), C2 ZIF/FFC (LCSC/Ali);
- D — филамент/крепёж.
