- UI и ввод — host-симулятор, не P4;
- USB-композит — только дескрипторы, не реальный枚举;

- P4-сборка не проверена (нет toolchain), проверена S3 и RP2040;
- CORE-2/PANEL-2 — схемы, без PCB и без бенчмарка реального времени.

5. Запас VSYS 3 % — помечен как исключение, требует проверки power-path.
