# BOM Букифон v1.0 — спецификация закупки

**Дата фиксации цен:** 2025-11-05 (ноябрь 2025). **Контракт:** v1.1, [`spec/50-v1.1.md`](../spec/50-v1.1.md).
**Валюта:** RUB (₽). Ориентиры курса на дату: USD ≈ 80 ₽, EUR ≈ 93 ₽, CNY ≈ 11 ₽.
**Область:** базовая комплектация v1.0 — CORE-1, PANEL-1, DECK-PAD, два аналоговых
модуля-примера (VCO-1, FILTER-1), макетный PROTO-1, корпус, кабели, питание.
Опциональные узлы (DECK-KEYS, LADDER-1, ENSEMBLE-1, FSR-velocity, 6.35 мм) посчитаны
отдельно и **не входят** в базовый итог.

Файл машинного формата — [`BOM.csv`](../BOM.csv): 13 колонок, разделитель `;`,
UTF-8 с BOM (открывается в Excel). Итоги ниже посчитаны из тех же данных.

## 0. Как читать и насколько верить ценам

- **Две цены на позицию** — «бюджет» и «оптимум»:
  - **бюджет** — AliExpress / LCSC / JLCPCB, самостоятельный заказ, доставка 3–6 недель;
    по многим позициям цена **оценочная** (помечена `~`);
  - **оптимум** — розница РФ (chipdip, platan, rekshop, quartz1 и др.), наличие/гарантия,
    быстрый срок; там, где ссылка ведёт на магазин, цена взята с его страницы.
- `~` перед ценой = **оценка ±30%** (нет подтверждённой карточки товара или цена
  зависит от партии/кратности). Без `~` — цена с открытой страницы магазина на дату сбора.
- Цены **за 1 шт, без доставки**, если не указано иное. Опт/кратность в примечании.
- Это **сводный** BOM проекта. Детальные BOM отдельных плат могут лежать в
  `hardware/<плата>/BOM-*.csv`; при расхождении количества по конкретной плате
  приоритет у локального BOM, а итоговые суммы здесь нужно пересчитать.
- Проверено с прямыми ссылками: **53 позиции из 114**. Остальные — оценка по аналогам
  (в основном пассив, крепёж, мелочь, импортные позиции Ali). Полный список
  оценочных позиций — §6.
- Цены розницы в РФ меняются на 10–20% в месяц; для закупки перепроверяйте наличие
  в день заказа. Себестоимость ниже — ориентир, а не коммерческое предложение.

## 3. Опции и «что можно не покупать в v1.0»

Проект задуман так, что v1.0 работает без всех опций ниже: ядро + панель + одна дека
+ два аналоговых модуля — это законченный инструмент. Опции — расширение.

| Опция | Что даёт | Бюджет, ₽ | Оптимум, ₽ | Когда брать |
|---|---|---:|---:|---|
| **DECK-KEYS** (42 Choc + SK6812 + MCP23017) | клавиатурная дека, 3,5 октавы | 2 486 | 5 083 | если нужна игра «как на клавиатуре», а не пэды |
| **FSR-velocity** (18 плёнок + 2×74HC4067) | чувствительность пэдов к силе удара | 2 620 | 4 880 | перкуссия, динамика; без неё velocity = 127 |
| **LADDER-1** (AS3320) | честный лестничный фильтр Муга | 1 694 | 2 760 | ради аналогового характера Муга |
| **ENSEMBLE-1** (BBD/PT2399) | ансамбль/хорус в духе Поливокса | 1 830 | 3 560 | ради «поливоксового» звука |
| **2-й VCO** (AS3340) | второй аналоговый генератор | 700 | 1 200 | если строите аналоговый дуофоник |
| **Платы опций** (3 конструкции) | DECK-KEYS, LADDER-1, ENSEMBLE-1 | 1 200 | 2 400 | только вместе с соответствующими опциями |
| **LINE OUT 6.35 мм** | гитарный/студийный разъём вместо 3.5 | 120 | 180 | если так удобнее на сцене |
| **Итого опций v1.0 (таблица выше)** | | **10 650** | **20 063** | |
| **Итого опций v1.1 (PWR-BATT-1, USB-C, AUDIO IN, EXPRESSION)** | | **2 070** | **4 200** | |
| **Всего опций** | | **12 720** | **24 263** | |

**Опции v1.1 — отдельный блок (`spec/50-v1.1.md`):**

| Позиция | Что даёт | Бюджет, ₽ | Оптимум, ₽ |
|---|---|---:|---:|
| Аккумулятор 1S2P 18650 (2 шт) + холдер + BMS + TP4056 + MT3608 | работа без розетки, заряд по USB-C | 1 090 | 2 220 |
| USB-C ×2 + USBLC6 | USB-C MIDI и USB-C «заряд» | 190 | 360 |

Аккумуляторный блок не заменяет внешний БП: при подключённом 12 В батарея заряжается
и не разряжается (ideal-diode / MOSFET-OR). Ёмкость сборки 5000–7000 мА·ч,
время работы ≈2–6 ч (`spec/50-v1.1.md` §1). Цены — AliExpress/Ozon, без доставки.

**Что можно не покупать в v1.0 (и сколько это экономит):**

1. **Вторую деку.** DECK-PAD и DECK-KEYS — альтернативы в одном посадочном узле.
   Оставьте одну: экономия 2 486 / 5 083 ₽ (плюс плата деки из B-02).
2. **FSR-velocity.** Без плёнок и мультиплексоров дека работает, velocity фиксированный:
   −2 620 / −4 880 ₽.
3. **LADDER-1 и ENSEMBLE-1.** Их характер (Муг/Поливокс) уже есть цифровыми моделями
   в прошивке (`spec/40-firmware.md` §2.1), аналог — «для тех, кто слышит разницу»:
   −3 524 / −6 320 ₽ (плюс платы опций, если нужны — строка B-02).
4. **PROTO-1** — это только плата в составе B-01, деталей не требует; можно не заказывать,
   если не планируете свои схемы (экономия — доля стоимости B-01, ~250–500 ₽).
5. **FILTER-1** — второй аналоговый модуль-пример; можно начать с одного VCO-1:
   −300 / −460 ₽ (LM13700) плюс плата.
6. **Принтер и филамент.** Если печатать на заказ (или есть доступ к принтеру), не покупайте
   PETG/TPU: −1 900 / −3 780 ₽, но услуга печати стоит 2 000–3 500 ₽ — считайте по месту.
7. **Расходники** (припой, флюс, изопропанол) — если уже паяете, не покупайте: −950 / −1 200 ₽.

**Минимальный вход (одна дека, без опций, без филамента, расходники есть):**
≈ **14000 ₽** (бюджет) / **27200 ₽** (оптимум). Этого достаточно, чтобы собрать
работающий Букифон и играть.
