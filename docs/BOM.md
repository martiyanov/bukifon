## 3. Что нового по сравнению с v1.0

- **MCU:** Pico RP2040 → **ESP32-P4** (32 МБ PSRAM, USB HS, RGB/DSI); ESP32-S3 — лайт-альтернатива
  (S3 не проходит 8×8 UAC2: 9.2 Мбит/с > FS; экран ~13 fps — `docs/11-esp32-feasibility.md`).
- **Дисплей:** 2.8″ 320×240 ST7789 → **5.0″ 800×480 IPS RGB, FPC-40**, голое стекло под вырез
  108×64.8 + драйвер подсветки ~19 В.
- **Панель:** 8 энкодеров → **16 EC11 (Ø14)**, 4 плечевых → **10 mini-jack** (Thonkiconn/PJ301M-12),
  2 слайдера 30 мм → **2 фейдера 60 мм** (китайские/ALPS RS60N11), Lapka-42 42 × Choc v1
  + hot-swap + 42 × 1N4148 + колпачки (печать).
- **Звук:** PCM5102A (DAC) + **PCM1808** (ADC, AUDIO IN для сэмплера/эффектора), 2 × MCP4728
  (6 CV out), MCP3208 (CV in/фейдеры/батарея), 2 × MCP23017 (+1 на кнопки), microSD.
- **Питание:** 1S2P 18650 + BMS + **TP4056 (USB-C)** / **BQ24074** (power-path) + **MT3608**
  12.2 В + MP1584/MC34063/AP2112 (12/±12/5/3.3 В).
- **Платы:** CORE-1 rev.3, PANEL-1 rev.2, DECK-KEYS-L42, DECK-PAD, PWR-1, 5 аналоговых
  картриджей, панель v0.5 (варианты A/B/C — в `mechanical/stl_v05_*`, появятся).

## 4. Что завтра (не входит в ночную дельту)

1. Сверить позиции/MPN с реальной схемой CORE-1 rev.3 и PANEL-1 rev.2 (после P1–P2).
2. Уточнить цены/наличие: ESP32-P4 (module vs EV-board), 5″ панель (40 vs 50-pin), ALPS RS60N11,
   BQ24074, thumbwheel/encoders с кнопкой; добавить поставщиков РФ.
3. Добавить пассивную обвязку по платам (резисторы/конденсаторы/разъёмы) из будущих BOM плат.
4. Перевести BOM.md в финальный вид (без «draft»), посчитать варианты «бюджет/оптимум» по РФ/импорту.
5. Синхронизировать с `spec/90` (R-12 MCU — после бенчмарка P1).
