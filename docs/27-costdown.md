# Cost-down: «народный» Букифон и первый SKU

Основание: консультация GPT по cost-down (полный текст — отчёт раунда) + разбор `BOM.csv`.
Ключевая мысль: **$271 в draft BOM — это не себестоимость изделия**, а «всё, что нужно
мастерской» (катушки филамента, наборы крепежа, расходники). После нормализации
product BOM цифры другие.

## 2. Нормализация product BOM (обязательно)

| Рычаг | Экономия $/шт | Потеря |
|---|---:|---|
| Отделить workshop/tooling (браслет, флюс, наборы крепежа) | 12–16 | нет |
| Считать фактический пластик: 279 г PETG вместо трёх катушек | 25–29 | нет |
| PCB-панелизация, партия 5–10 | 12–20 | оборотный капитал |
| EC11 оптом $0.65–0.90 вместо $1.75 | 14–18 | нужна квалификация образцов |
| Choc + hot-swap партией 100+ | 5–8 | заморозка денег |
| microSD/кабели — опции | 9–12 | нет карты/кабеля в коробке |
| Ручки/колпачки — печать PLA/PETG, без TPU | 3–6 | чуть хуже хват |

**Результат:** P4-база после нормализации — **$205–225**, S3 — **$183–202**.
То есть 30–40 % экономии достигается закупкой и учётом, а **не** удалением органов управления.

## 3. S3-версия — это отдельная CORE-S3, а не «вставили другой модуль»

| Узел | S3-версия |
|---|---|
| MCU | ESP32-S3-WROOM-1-N16R8, **8 МБ PSRAM обязательны**, 16 МБ flash |
| ESP32-C6 | DNP (Wi-Fi/BLE уже в S3) |
| USB | FS: HID + MIDI + CDC + **стерео** UAC; 8×8 UAC2 не обещать |
| Экран | PANEL-2 RGB565 оставить; целиться в 10–20 fps full / partial redraw |
| PCM5102A / PCM1808 | оставить (без ADC нет сэмплера) |
| Питание | убрать C6-LDO и P4-обвязку; 3.3 В buck-boost от VSYS; ±12 В — с PWR-2/DNP |
| PANEL-2 / корпус | без изменений |
| PWR-2 | 1S-вариант, ±12 В DNP без картриджей |

Цена S3-базы: текущий BOM с заменой P4→S3 ≈ $257; нормальный product BOM партии 5 —
**$195–205**; партия 10–25 с оптом — **$183–195**; kit без карты/БП/батареи — **$170–185**.

Ограничения S3 (GPIO/USB/дисплей) и профиль тестов — [docs/31](31-core-s3-constraints.md):
1-bit SD, один framebuffer + dirty rects, USB FS stereo UAC2 (не 8×8), TPS63802.

**Вывод:** retail **$199** возможен только для **kit/direct-sale** с почти нулевой маржой;
собранный прибор за $199 пока нереалистичен.

## 4. Батарея: 2×18650 или LiPo 5000 мА·ч

| Вариант | Цена | Сборка | Безопасность | PWR-2 |
|---|---:|---|---|---|
| 2×18650 в держателях, 1S2P | $9–12 | легко менять, но опасны разные банки/переполюсовка/плохой контакт | худший | текущая схема |
| Сваренный matched 1S2P pack + PCM/NTC | $12–18 | повторяемо | лучший цилиндрический | убрать держатели |
| LiPo pouch 1S 5000 мА·ч + PCM/NTC | $11–20 | проще | нет ошибок установки, но чувствителен к проколу | электрически почти без изменений |

**Рекомендация:** не продавать kit с россыпью 18650. Собранный аппарат — сертифицированный
1S LiPo или сваренный 1S2P с NTC; для DIY-kit батарея — опция (старт от внешнего БП).

## 5. Корпус: экономия времени, не денег (обновлено: фактические числа B-light)

Сделана облегчённая версия корпуса **v0.5-B-light** (клин 8°, панель и все 83 выреза —
без изменений из `spec/panel-spec-v0.4.json`). Файлы: `mechanical/stl_v05_B_light/`,
рендеры `mechanical/preview_v05_B_light/`, fitcheck — 0 конфликтов, watertight.

| Параметр | B (0.4 мм, 2 периметра, 25 %) | **B-light (0.6 мм, 3 периметра, 10 %)** | Δ |
|---|---|---|---|
| Масса комплекта (модель) | 277 г | **≈ 230 г** | **−47 г (−17 %)** |
| Время печати | 18.3 ч | **≈ 11.1 ч** | **−7.2 ч (−39 %)** |
| Стенки / дно | 2.5 / 3.0 мм | 2.0 / 1.8 мм | −0.5 / −1.2 мм |
| Периметры / инфилл | 2 / 25 % | 3 (локально 4) / gyroid 10 % | жёстче оболочка |
| Рёбра | 8 стеновых | 8 стеновых + 6 локальных (экран, фейдеры, шов) + 2 седла батареи | локальная жёсткость |
| Жёсткость | базовая | сохраняется (3 периметра = 1.8 мм в стенке 2.0; 4 периметра у винтов/шва/стоек) | тест на кручение 10 Н·м |
| Риски | — | тоньше дно → возможен «барабан» на НЧ; панель-оболочка требует локальных рёбер; 0.6 сопло грубее | тест 1 половинки + 1 панели |

**Вклад шагов (модель, калибрована по базе B = 277 г / 18.3 ч):**

| Шаг | Масса | Время |
|---|---|---|
| B — база | 277 г | 18.3 ч |
| + профиль 0.6 мм / слой 0.30 (−7 % материала) | 257 г (−19) | 12.4 ч (−5.9) |
| + стенки 2.0 / дно 1.8, лёгкий ложемент батареи, стойки Ø6.4 | 208 г (−50) | 10.0 ч (−2.4) |
| + 3 периметра / 10 % gyroid / локальные рёбра (жёсткость) | **230 г (+22)** | **11.1 ч (+1.0)** |

**Компромисс по панелям.** Если печатать панели 3 периметрами по всей площади,
3-мм пластина выходит ~80 % сплошной: комплект ≈ 408 г / 19.7 ч — цель не достигается.
Поэтому панели печатаются «оболочкой»: 3 периметра по контуру/окнам, 1 периметр в поле,
10 % + локальные рёбра-модификаторы (в модели эффективная доля 0.30). Геометрия панелей
и вырезы при этом не меняются.

**Вариант C (12° + отсек + подставка).** Для сравнения: корпус C с закрытым
батарейным отсеком 1S2P и складной подставкой — **≈ 314 г / 20.8 ч** (стандартный
профиль 0.4/2 периметра/25 %; body 427 см³ + крышка 18.2 + подставка 20.7).
C не заменяет B-light: это нишевый вариант «максимальный клин + автономность»,
+36 % массы к B-light. Подробнее — `docs/45-case-variants.md`.

**Вердикт §5:** цель **225–245 г / 11–14 ч** достигнута: **≈ 230 г / 11.1 ч** при
сохранении жёсткости (3 периметра + рёбра) и печати без поддержек. Денежная экономия
пластика ≈ $0.25–0.5/шт; реальная выгода — загрузка принтера (−39 % времени).
Перед партией напечатать 1 половинку корпуса и 1 панель, замерить массу/время;
если «звенит» — вернуть стенки 2.2 / дно 2.0 (+~20 г, +~1 ч, ≈250 г / 12.1 ч — всё ещё в цели).

## 6. Дефицит и подделки (РФ)

| Позиция | Риск | Замена/политика |
|---|---|---|
| ESP32-P4NRW32 (32 МБ PSRAM) | новый компонент, сложно проверить модуль | только трассируемый поставщик; fallback S3-N16R8 |

| AS3320/AS3340 | нишевые ИС, перемаркировка | картриджи — не в базу; LM13700/SSI2144/discrete ladder |

## 7. Открытые конфликты — рекомендации GPT

| Конфликт | Решение |
|---|---|
| +5 В 1.0→1.6 А | не питать 3.3 В MCU через `1S→+12→MP1584` (двойное преобразование и шум); для 1S — отдельный 3.3 В buck-boost от VSYS; +5 В считать 1.6 А с запасом ≥25 % |
| VSYS 3 А vs 2.74–3.38 А | аппаратный/прошивочный лимит LED, последовательный запуск рельсов, профиль «battery»; полная яркость + картриджи — только внешний БП |
| J3 IDC-20 vs Micro-Fit | **сразу Micro-Fit 3.0** для силовых (≥2 контакта VSYS, 3–4 GND); IDC — только сигналы |
| 1S2P vs 2S | первый kit/P4 — **1S** (BQ24074 и архитектура уже 1S); 2S — отдельная PWR-3 для мощного full-варианта |
| TPS61088 +12 В | оставить для прототипа, квалифицировать ripple/тепло (запас по верхнему пределу мал) |
| Автономность | первый релиз квалифицировать прежде всего от внешнего БП; батарея — не блокер PCB/firmware |

## 8. Первый SKU

**S3-base kit, $199, партия 10–25, direct-sale, статус limited DIY/beta** (не «массовый прибор»).

| В kit | Опционально |
|---|---|
| CORE-S3, PANEL-2, упрощённый PWR, дисплей | аналоговые картриджи |
| корпус и крепёж, 42 Choc, hot-swap | премиальные колпачки |
| 16 EC11, 2 фейдера, 10 джеков | microSD |
| PCM5102A + PCM1808, CV/GATE | БП 12 В |
| один внутренний USB-C кабель/шлейфы | аккумуляторный pack |
| печатные ручки и базовые колпачки | USB-кабель, сумка |

Порядок SKU: **S3-base $199** → **P4-стандарт $299** (после P1) → **full $399** (опциональный
bundle картриджей). Не урезать 42 клавиши, 16 энкодеров, 5″, PCM1808 и hot-swap — это и есть
«народность».

## 9. Вердикт (5 строк)

1. Первый SKU — **S3-base kit $199**, партия 10–25, direct-sale; собранный прибор дороже.
2. Не урезать клавиши/энкодеры/экран/ADC/hot-swap.
3. $70–85 экономии — правильный product BOM, опт EC11/Choc, амортизация PCB.
4. Питание первого релиза: 1S pack или внешний БП, LED-cap; J3 — Micro-Fit.
5. P4 $299 — вторым после P1; $399 full — только опционный bundle.
