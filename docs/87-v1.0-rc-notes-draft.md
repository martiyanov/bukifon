# v1.0-rc — черновик release notes (не выпущено)

Статус: **draft**; тег `v1.0.0-rc.1` ставится только после ворот G5–G10 (docs/75).
Цель: зафиксировать, что войдёт в RC и как это проверить.

## Что войдёт

- **Железо:** CORE-2 rev.3 (P4), PANEL-2 rev.3, PWR-2 rev.1 (после PWR 13/13 и P1);
  герберы/CPL в `fab/` (docs/83) — появятся после MCU freeze.
- **Корпуса:** A/B/B-light/C + B_mic/C_mic; STL/3MF/STEP, paperkit, сборочная карта.
- **Прошивка:** UI 800×480 RU/EN (кириллица), 7 вкладок, 12 треков (4+8), GEN, project v2,
  factory self-test 21, Module SDK v0.2, P4 bring-up app.
- **Документация:** 87+ документов, FAQ, ограничения, day-1 runbook, сборка в РФ, cost-down,
  supply-риски, аналоги, пресс-кит.
- **Веб:** демо RU/EN (PWA/веб-приложение — backlog, docs/86).

## Критерии приёмки (из docs/36)

- [ ] 8 сценариев RC DoD пройдены на собранном экземпляре;
- [ ] self-test 21/21 на 3–5 прототипах;
- [ ] UX blind-тест 5 людей: time-to-sound ≤10 с, ≥4/5;
- [ ] PWR 13/13, P1 max block ≤650 µs, MCU freeze зафиксирован;
- [ ] PCB rev.1: DRC/DFM 0, fab-пакет проверен;
- [ ] recovery/прошивка/серийники проверены;
- [ ] release bundle: SHA256 0 нарушений, PII ok, SBOM, лицензии.
