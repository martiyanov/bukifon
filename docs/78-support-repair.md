# Поддержка и ремонт (v1.0-rc)

Практический гид: что делать, если инструмент не включается/не звучит/не видит карту; какие
запчасти менять; как восстановить прошивку; что покрывает гарантия, а что — DIY.

## 1. Быстрая диагностика

| Симптом | Проверить | Решение |
|---|---|---|
| Не включается | USB-C кабель/БП (5 В ≥1.5 А), предохранитель F1, PWR_GOOD | другой кабель/БП; F1 — только сервис |
| Включается, нет звука | MASTER/VOL, PAIR LEVEL, mute партии, наушники/выход | поднять уровень; снять mute; проверить джек |
| Экран тёмный/рябь | FPC-40 дисплея, питание подсветки, reset | переподключить FFC (ZIF), проверить BL |
| Микрофон не пишет | SW1/SW3 MIC, LED MIC ON, GAIN/THRESH | включить mute-свитч, проверить LED, поднять gain |
| Битбокс не заполняет | шум/SENS, близость | поднести микрофон, SENS вверх |
| Секвенсор не идёт | PLAY, BPM, пустой паттерн | PLAY/паттерн/темп |
| EXT-синт молчит | канал/PC, DIN OUT vs IN, clock | см. docs/77 §5 |
| Карта SD не видна | FAT32 ≤32 ГБ, контакты | переформатировать, вставить до щелчка |
| Не прошивается | BOOT+RESET, UART0 (TX/RX/GND), драйвер | recovery-режим docs/42 |

## 2. Восстановление прошивки

1. **BOOT + RESET** → recovery UART0 (115200), 3.3 В USB-UART (TX↔RX, GND).
2. `esptool.py --chip esp32p4 -p /dev/ttyUSB0 write_flash 0x0 bukifon_p4.bin` (или OTA-файл).
3. Дождаться self-test 21/21; при FAIL — таблица docs/42 §8.

## 3. Запчасти (расходники/быстрая замена)

| Узел | Что купить | Примечание |
|---|---|---|
| Клавиши | Kailh Choc v1/v2 + hot-swap | Lapka-42, 42 шт |
| Энкодеры | EC11 (16 шт) | с кнопкой, 20 детентов |
| Фейдеры | 60 мм, 10 кОм (2 шт) | линейные |
| Джэки | Thoniconn 3.5 мм mini-jack | 10 шт |
| Дисплей | HotLCD 5″ 800×480 RGB565 + FPC-40 | проверить pinout перед заказом |
| Микрофон | ICS-43434 + сетка/поролон | MEMS I2S; SPH0645 — другой footprint |
| USB | USB-C рецептакл 16p | при вырванном разъёме — сервис |
| Предохранитель | F1 по BOM-PWR | только сервис/пайка |

## 4. Гарантия/DIY

- **Гарантия 12 мес** на дефекты сборки/компонентов (кроме механических повреждений и влаги).
- **DIY разрешён**: открытая схема/прошивка, self-test 21; замена клавиш/энкодеров/фейдеров/джеков
  не снимает гарантию, если не повреждена плата.
- **Не покрывается**: вода/перегрев/питание выше спецификации, пайка на BGA/QFN, вырванные пады.
- Ремонт — либо сервис (docs/72 мастерские), либо самостоятельный по `hardware/` и `docs/34`.
