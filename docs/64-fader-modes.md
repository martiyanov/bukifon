# Фейдеры: режимы работы (Octatrack-сцены, DJ, модификаторы)

Требование заказчика: фейдеры должны уметь **как в Octatrack**, но также работать как
**диджейские** и иначе — например, в комбинации с клавишей менять громкость.

## 1. Режимы (переключаются на экране / кнопкой)

| Режим | FADER 1 | FADER 2 | Для чего |
|---|---|---|---|
| **TRACK** | уровень выбранной партии | мастер-громкость | обычная работа с треками |
| **SCENE (Octatrack)** | **кроссфейдер A↔B**: морфинг параметров между сценами A и B | мастер-громкость | живое «плавное переключение» звука |
| **DJ** | уровень DECKS A (партии 1–2) | уровень DECKS B (партии 3–4) | диджейский кроссфейд |
| **MACRO** | свободный макрос (назначается) | свободный макрос | персональные раскладки |
| **MOD** (удержание) | пока зажата Fn/клавиша — всегда мастер-громкость | — | быстро поправить громкость в любом режиме |

## 2. Octatrack-сцены: как это работает

- У каждой партии (или всего паттерна) есть **Scene A** и **Scene B** — наборы значений
  параметров (cutoff, resonance, drive, ADSR, delay …).
- **Кроссфейдер** интерполирует между A и B: крайнее левое — A, крайнее правое — B,
  середина — смесь. Это не «переключение», а непрерывный морфинг.
- Назначение параметра в сцену: **удержать энкодер + двинуть фейдер** (или экран SCENES:
  выбрать параметр → A/B). В v1.0-rc — не более 8 параметров на сцену.
- Сцены сохраняются с проектом; переключение сцен — кнопками (след/пред), кроссфейдер — плавно.
- Индикация: на экране «SCENE A ← [FADER] → SCENE B», текущее значение сцены, список
  назначенных параметров и их A/B значения.

### Почему это удобно
- Плавные переходы между «состояниями» звука без скачков;
- один фейдер = живой макроконтроль (фильтр/драйв/эффекты);
- воспроизводимость: сцены сохраняются.

## 3. DJ-режим

- FADER 1 = DECKS A (партии 1–2), FADER 2 = DECKS B (партии 3–4);
- равенство мощностей (equal-power crossfade), чтобы середина не «проваливалась»;
- при удержании Fn — мастер-громкость (не сбивая кроссфейд);
- дополнительно: cue/mute быстрым нажатием, экран показывает уровни A/B.

## 4. Модификаторы и комбинации

| Действие | Результат |
|---|---|
| Fn/Shift + фейдер | мастер-громкость (временная, без потери текущего режима) |
| Fn + энкодер | назначить параметр в сцену A/B |
| двойной клик по фейдеру | вернуть в центр / 0 dB (с undo) |
| long-press | показать назначение фейдера (overlay) |
| фейдер + PLAY | «записать» движение в сцену? (backlog v1.1) |

Важно: **no-jump** — при смене режима фейдер не перескакивает, а «подхватывает» значение
(pickup) или показывает разницу; значения сохраняются per-mode.

## 5. Аппаратно

- 2 фейдера 60 мм, 10 кОм, линейные; АЦП MCP3208 (CH2/CH3) — 12 бит;
- сглаживание 5–10 мс, деадбенд, без щелчков;
- калибровка min/max при сборке (self-test);
- в прошивке — единый `FaderManager`: режимы, кривые (linear/equal-power), pickup, undo.

## 6. Критерии приёмки

| # | Тест | Критерий |
|---|---|---|
| 1 | Переключение режимов | без скачков параметров, значения per-mode сохраняются |
| 2 | SCENE-морфинг | A/B интерполируются плавно, ≤8 параметров, без звона |
| 3 | DJ-кроссфейд | equal-power, середина без провала, нет клиппинга |
| 4 | Fn + фейдер | мастер-громкость меняется, режим не теряется |
| 5 | Двойной клик | центр/0 dB с undo |
| 6 | 24 ч | без дрейфа/дребезга |
