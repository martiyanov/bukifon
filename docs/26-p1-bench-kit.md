# P1: стенд для бенчмарка — что купить, как собрать, как измерить

Цель P1 — ответить на единственный вопрос: **какой MCU тянет Букифон** (8 моно-дорожек
+ 8 голосов + экран 800×480 + USB UAC2) с запасом. Без стенда нельзя фиксировать ни MCU,
ни PCB. Workload и критерии — [docs/05](05-benchmark-workload.md), как запускать —
[docs/05a](05a-benchmark-howto.md), **протокол приёма стендов P4/H743 — [docs/56](56-p1-measurements.md)**,
харнесс — [firmware/bench](../firmware/bench/).

## 1. Закупка (минимальный комплект)

| # | Позиция | Зачем | Ориентир |
|---|---|---|---|
| 1 | **ESP32-P4-Function-EV-Board** (32 МБ PSRAM) или P4-модуль на переходке | основной кандидат | $55–70 (EV) / $8.5 (модуль) |
| 2 | **Nucleo-H743ZI2** (STM32H743) | контрольный кандидат | ~$30 |
| 3 | ESP32-S3-DevKitC-1 N16R8 (8 МБ PSRAM) | **полноценный профиль S3-base** (первый SKU): 4 МиБ pool + FB, 1-bit SD, RGB, stereo UAC | ~$10–13 |
| 4 | PCM5102A DAC-модуль + PCM1808 ADC-модуль | аудио in/out для тестов | $3–6 каждый |
| 5 | Дисплей 5.0″ 800×480 RGB FPC-40 + переходная плата | UI-сценарий | $12–18 |
| 6 | microSD-модуль + карта 32 ГБ | SD worst-case | $5 |
| 7 | USB-C кабель данных + USB-C хаб с внешним питанием | HS UAC2 и питание | $10 |
| 8 | Лабораторный БП 0–30 В / 5 А с ограничением тока (или battery simulator) | питание и просадки | $40–80 |
| 9 | Электронная нагрузка (или мощные резисторы + реле) | рельсы и load-step | $25–60 |
| 10 | Осциллограф ≥100 МГц, 2 канала + пружинный ground | ripple/шум | есть/аренда |
| 11 | Логический анализатор 8–16 каналов (I2S, SPI, I2C, USB) | протоколы | $10–20 |
| 12 | Мультиметр, термопара/ИК-термометр | ток/тепло | есть |

Минимум для вердикта по MCU: пункты **1–4 + 7–10**. Дисплей и SD нужны для «вертикального»
теста (P2), их можно докупить позже.

## 2. Схема стенда

```
USB-C (данные) ── ПК (bench runner, serial 115200)
      │
DevKit (P4 / H743 / S3)
 ├─ I2S out → PCM5102A → LINE OUT (RCA/3.5) → аудиокарта ПК
 ├─ I2S in  ← PCM1808  ← генератор/шум
 ├─ SPI → дисплей 800×480 (RGB/FPC-40)
 ├─ SDIO/SPI → microSD
 ├─ USB → UAC2 8×8 тест (ПК видит интерфейс)
 └─ UART0 → лог bench (JSON)
Питание: lab PSU 5 В с ограничением 2 А; ток мерить последовательно (или INA219).
```

## 3. Прошивка и запуск

```bash
# host sanity (без железа)
make -C firmware/bench host

# S3
PLATFORMIO_CORE_DIR=/tmp/piocore pio run -d firmware -e bench_s3 -t upload

# P4 / H743 — окружения подготовлены в firmware/platformio.ini, см. docs/05a
```

Устройство печатает таблицу и JSON по serial. 24-часовой soak:
`-DBUKIFON_BENCH_SOAK_HOURS=24`.

## 4. Протокол измерений (порядок)

1. **Питание:** 5.0 В, ток покоя; пиковый ток при полной нагрузке (дисплей 100 %, LED, USB, SD).
2. **Аудио-ядро:** сценарии fm_voice, granular_track, mix_bus — max/p50/p95/p99 времени
   блока, overruns. Критерий: max ≤ 650 µs, p99 ≤ 500 µs, 0 overruns.
3. **PSRAM/SDRAM:** granular random-read (линия 64 Б, 8–16 сэмплов) — МБ/с и промахи;
   сравнить с 24.6 МБ/с, которые требует workload.
4. **UI:** полная и частичная перерисовка 800×480 — fps и время flush; цель ≥30 fps full,
   ≥60 partial.
5. **USB:** UAC2 8×8/24/48 — видит ли ПК интерфейс, стабильность 10 минут, дропы.
6. **SD:** worst-case запись/чтение, 4 КиБ random, время отклика.
7. **Soak:** 24 часа — 0 xruns, 0 watchdog, память без утечек.
8. **Тепло:** термограмма MCU/PSRAM/стабилизаторов через 60 минут.

Результаты — в `firmware/bench/results/<platform>.json` и таблицу в [docs/05](05-benchmark-workload.md) §9.

Заполняется после стенда. **Правило:** если P4 и H743 оба проходят — выбираем P4

## 6. Бюджет стенда

| Вариант | Состав | Оценка |
|---|---|---|
| Минимальный | P4 EV + H743 + PCM5102A + PCM1808 + кабели | ~$110–130 |
| Полный | + S3 + дисплей + SD + лог. анализатор | ~$160–200 |
| С нагрузкой | + лабораторный БП/электронная нагрузка | ~$230–320 |

## 7. Что НЕ делать до стенда

- Не заказывать CORE-2/PANEL-2/PWR-2 (статус PRE-FREEZE).
- Не фиксировать Module SDK v1 (API зависит от реального бюджета).
- Не выбирать 1S2P vs 2S окончательно (см. O-6).
- Не обещать «8 стерео-дорожек» — cut-list после замеров.
