# Известные ограничения (честно, до покупки)

Это не «недостатки, о которых умолчим», а осознанные границы версии. Обновляется с каждым
релизом; для v1.0-rc перечисленное считается нормой.

## 1. Версии и звук

| Ограничение | Где | Версия/план |
|---|---|---|
| **S3-base: SPI-экран 800×480** (10–20 fps partial, full ~13 fps), без RGB/DSI | CORE-S3 (lite) | P4 — RGB565/DSI; S3 — lite, позже |
| **USB 8×8 UAC2 — только P4/HS**; S3 — stereo FS (UAC1/2) | S3 | по железу |
| 8 моно-дорожек / до 6 голосов (S3-lite); P4 — 8 стерео/8 голосов | CPU | без изменений |
| 4-оп FM + wavetable + SVF; нет полноценного физического моделирования | DSP | v1.x модули/картриджи |
| **Многодорожечный лупер — backlog** (v1.1), в v1.0 только ресемплинг | софт | R-30 |
| **Вокодер — v1.1** (8–16 полос) | софт | R-39 |
| Нет p-lock на внутренних партиях (p-lock CC — только внешние MIDI-треки, 1 CC на шаг) | seq | v1.1 (4 CC, внутренние) |
| Нет USB-MIDI **host** (P4 умеет, нужен порт/режим) | железо | rev.3 опция |

## 2. Микрофон

| Ограничение | Детали |
|---|---|
| **Не студийное качество** | MEMS ICS-43434 + MAX9814 AGC: идеи, битбокс, вокодер; не вокал «на запись» |
| Акустика зависит от корпуса | порт/сетка/поролон; SNR/изоляция от WS2812/BL проверяются на образце |
| Шум вентилятора/комнаты | AGC поднимает и шум; есть THRESH/VAD |

## 3. Питание/железо

- **Батарея в первой партии не продаётся** (внешний БП), позже — 1S LiPo/сваренный 1S2P (D-39/D-56);
- **±12 В**: +12 В 330 мА, −12 В 95 мА (для шины модулей) — не «модульный монстр»;
- **J3** — прототип IDC-20, rev.2 Micro-Fit (D-40); 3 А — на границе для IDC;
- **SDIO 4-bit → 1-bit** на CORE-2 rev.3 (освободили пины под микрофон); ~6 МБ/с, для 8 дорожек хватает;
- все платы **PRE-FREEZE**: заказ PCB — только после PWR 13/13 и P1-замеров.

## 4. Корпус/эргономика

- **B-light 231.4 г** — «народная» версия; жёсткость проверяется печатью половинки (docs/35);
- **A (flat)** — студийный/настольный, не для игры «на коленях»;
- **C (12°)** — нишевый: зад 76.6 мм вне допусков docs/21;
- **Порт микрофона/клипсы — только в B-light** (A/B/C — без порта; при желании — правка генератора).

## 5. Софт/экосистема

- **Module API v0** экспериментальный, бинарная совместимость не гарантируется;
- **Преcеты**: 8 слотов, хранение host-файл (NVS на железе — TODO(hw));
- **Share паттерна** — через URL только в демо (на железе — позже);
- **DAW/USB-KBD** — базовые режимы (HID+MIDI), не «полный контроллер»;
- **Wi-Fi/BLE** — каркасы; аудио по сети/BLE-MIDI — после v1.0;
- **Нет OTA-сервера/облака**; обновление — USB.

## 6. Документация/сборка

- Цены в BOM — **±30 %**, не RFQ; финальный landed cost — после заказов;
- Сборка — подрядчики РФ (docs/72), не «из коробки»;
- Герберов/CPL пока нет: появятся после MCU freeze и PCB rev.1;
- FPC-40 дисплея: MPN/pinout фиксируется образцом (`TFT-H050A1SVIST4R40` + проверка).

## 7. Что НЕ является ограничением (специально)

- 42 клавиши Lapka-42, 16 энкодеров, 5″ 800×480, 10 джеков, 2 фейдера — остаются;
- открытость (KiCad/C++/STL), ремонтопригодность, тест-поинты, QR/серийники — остаются;
- «народная» цена — цель, а не обещание: см. docs/37.
