# Медиа и размер репозитория

Правило: артефакты, которые видит пользователь, должны быть **лёгкими и в правильном формате**.
Проверка при релизе — `bash tools/check_repo_size.sh` (добавить в `check_all` при желании).

## Форматы

| Тип | Формат | Ориентир |
|---|---|---|
| 3D-рендеры, превью, фото | **JPEG q85**, ≤1600 px, ≤300 КБ | `tools/optimize_images.sh` |
| UI-скриншоты (плоский текст) | **PNG** (мал) или WebP lossless | ≤80 КБ |
| Схемы KiCad | **PDF** (основной) + **.svg.gz** (сжатый экспорт); `.svg` в рабочем дереве не держим | `tools/compress_svg.sh` |
| Чертёж 1:1 | PDF | ≤2 МБ |
| STL/3MF | как есть (STL — бинарный) | — |
| STEP | `.step.gz` в архиве старых версий | — |

Причина: 60 PNG-рендеров весили ~83 МБ и были заменены на JPEG (60 файлов, экономия ~83 МБ);
19 KiCad-SVG весили ~50 МБ и сжаты в `.svg.gz` (экономия ~46 МБ). Итог: рабочее дерево
**72 МБ** вместо ~218 МБ.

## Правила

1. Новые рендеры/превью коммитить **только JPEG** (для фото/3D) — PNG лишь для скриншотов с текстом.
2. Перед коммитом: `bash tools/optimize_images.sh --dry-run` — посмотреть, что будет сжато.
3. KiCad-экспорт: коммитить PDF и `.svg.gz`, не `.svg` (или запускать `tools/compress_svg.sh`).
4. Старые версии — в **git-тегах/fresh-bundle**, не в рабочем дереве (архивные папки удалены 06.11.2025 по решению владельца; AGENTS §4a скорректирован этим решением).
5. Release bundle (`tools/make_release_bundle.sh`) включает только нужное: STL/3MF, PDF, BOM, docs,
   прошивку; тяжёлые исходники (STEP, старые SVG) — в архив, не в bundle.

## Проверка

```bash
bash tools/check_repo_size.sh   # размер tracked-файлов и топ-10 тяжёлых
bash tools/optimize_images.sh --dry-run
bash tools/compress_svg.sh      # идемпотентно: уже .svg не трогает
```
