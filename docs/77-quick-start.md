# Быстрый старт: идея за 10 минут

Короткая инструкция для нового владельца. Подробно — [docs/36](36-rc-definition.md) (сценарии),
[manual](https://martiyanov.github.io/bukifon/demo/) (веб-демо с подсказками).

## 0. Включить (0:30)

1. Подключить USB-C (питание+данные) или внешний БП.
2. Дождаться логотипа — 2–3 с; экран покажет **PART 1 · SELECTED · PAGE MAIN**.
3. Если нужен микрофон — включить **SW1/SW3 (MIC)** на корпусе; LED «MIC ON» горит.

## 1. Получить звук (1 мин)

- Нажать любую клавишу — звучит текущий пресет. Крутить **А–Г** (левые верхние) — параметры страницы MAIN.
- **PLAY** — запустить секвенсор; **STOP** — остановить.
- **HOME** — всегда вернуться в MAIN одним жестом.

## 2. Найти параметр (2 мин)

- **Зеркальная карта**: у каждой ручки своя ячейка на экране — левые 8 (А–З) = страница,
  правые 8 (И–П) = макросы (CUT/RES/ATK/REL/DLY/DRV/CRSH/MST).
- Страницы: **MAIN/FM/ENV/FX/GEN/EXT/MIC** (кнопки/табы); L2 — один жест.
- **Shift** (удержание) — подсказка слоёв/жестов.

## 3. Своя идея (3 мин)

- **Секвенсор**: 16 шагов, 4 внутренние партии + 8 внешних MIDI-треков (EXT).
- **GEN**: PROB/EUCLID/MUTATE/SCALE/ARP/EVOLVE — генеративность на выбранный трек;
  **UNDO** откатывает (Ctrl+Z).
- **Запись партии**: REC + играть; **ресемплинг**: REC в любой момент → PAD.

## 4. Голос (3 мин)

- **MIC → REC MIC** → PAD «VOICE nn» (до 30 с; авто-обрезка тишины).
- **BEATBOX → STEPS**: настучать ритм — шаги заполнятся (kick/snare/hat), UNDO откатывает.
- **Вокодер** — v1.1 (backlog); сейчас голос = сэмпл/ритм.

## 5. Внешние синтезаторы (2 мин)

1. MIDI-кабель DIN OUT (или USB-MIDI) → внешний синт; канал/PC — на странице **EXT**.
2. Транспорт/clock — общие: PLAY/STOP, clock 24 ppqn.
3. P-lock CC: удержать шаг + крутить энкодер (1 CC на трек в v1.0-rc).
4. Сохранение: **SAVE** (пресет/проект), **LOAD**.

## 6. Если что-то не так

| Симптом | Решение |
|---|---|
| Нет звука | MASTER/VOL, PAIR LEVEL, кабель наушников/выхода; PART mute |
| Не слышно микрофон | SW1/SW3 MIC включён? GAIN/THRESH на странице MIC; LED MIC ON |
| Битбокс не пишет шаги | SENS/THRESH, шумно в комнате; настучать ближе к микрофону |
| Секвенсор «не играет» | PLAY, tempo/BPM, PATTERN не пустой; EXT-треки — канал/PC |
| Нет внешнего синта | MIDI-канал, кабель DIN OUT (не IN), clock/transport |
