## Где проект сейчас

**Готово и проверено**
- панель 380×210 (0 пересечений), 4 корпуса (A 302 г, B 277 г, B-light 230 г/11.1 ч, C 314 г);
- платы pre-freeze: CORE-2 rev.2 (P4+C6, ERC 0/0), PANEL-2 rev.2, PWR-2 rev.1 (ERC 0/0), CORE-S3 rev.0;
- DFM/DFT: 30 TP, 20 self-test, serialization (24C32+flash+QR), recovery, чек-листы;
- product BOM P4 ($223/$198/$180 на 1/10/25), закупочный лист $784;
- прошивка: host 226/226 тестов, UI 4 режима + 4 темы + GEN, SDK v0.1, bench (P4 профиль PASS-модель);
- веб-демо: 800×480, 16 энкодеров, кластеры ±18°, фейдеры TRACK/SCENE/DJ, REC-ресемплинг, 9/10;
- home-offload: `pole` (8 ядер, RTX 3060), host-тесты **248/248**, **ESP-IDF P4 собирается** (`bukifon_p4.bin` 250 КБ).

**Блокеры / ждут**
1. **Заказ стендов** (P1 $426, PWR $277, LCD-адаптер $73, печать $42) — критический путь к PCB.
2. **Репозиторий**: пересоздать (docs/41) / GitHub purge — PII в старых SHA.
3. **Печать тестовой половинки** B-light (70 г/3.4 ч).
4. **ESP-IDF P4 сборка** — установка идёт на `pole`; нужен devkit для прошивки.
5. **PVR-2 13 измерений** — журнал docs/51 готов, нужны EVM/bare-IC.

блокеры, план на день, риски).
