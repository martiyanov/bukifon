## Где проект сейчас

**Готово и проверено**
- панель: 42 клавиши, 16 энкодеров, 5″ 800×480, 10 джеков, 2 фейдера — 0 пересечений;
- корпуса: v0.4 (плоский), v0.5-B (8°, 277 г), B-light (8°, 230 г / 11.1 ч) — все watertight, fitcheck 0;
- электроника: CORE-2 rev.2 (P4+C6, ERC 0/0), PANEL-2 rev.2 (ERC 0 err/6 warn), PWR-2 rev.1 (ERC 0/0),
  CORE-S3 rev.0 (ERC 0/0) — все **PRE-FREEZE**;
- прошивка: host-демо UI 800×480, секвенсор 4×16, save/load, Module API v0, 120/120 тестов;
- бенчмарк: workload freeze + harness, host PASS (worst 218 µs = 16.4 % дедлайна);
- SDK: API v0 + каталог + примеры + валидатор + CI;
- безопасность: история очищена, сканер, политика; purge-запрос готов.
