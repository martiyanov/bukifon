## Отличия C

- **Наклон 12°** (перепад 44.6 мм) — сильнее «пультовая» эргономика, но выше задняя
  часть; экран/ручки выше, клавиши дальше.
- **Батарейный отсек 1S2P 18650**: закрытый (X 292…372, Y 54…134), крышка снизу
  86×86×2.5 на 4×M3 (цековка), банки лежат на крышке; доступ снизу без разборки.
- **Складная подставка**: отдельная печатная U-деталь 148×67×6, крепление 2×M3
  по оси сзади (X 116/264, Z8); в сборе — отдельная деталь, при работе
  откидывается, в сложенном виде за корпусом.
- **Кабельный канал** 100×10 в задней стенке/полу — для шлейфа/кабеля батареи.
- Панель, крепёж панели (4×M3), PANEL-2 (6×M3), CORE-S3/PWR-2 — как у B.

## Что когда печатать

1. **B-light** — по умолчанию для «народной» версии: 230 г / 11.1 ч, 3 периметра,
   gyroid 10 %, fitcheck 0. Печать: `docs/35-print-first.md`.
2. **B** — если нужен запас жёсткости/классический PETG-профиль (277 г / 18.3 ч).
3. **A (flat)** — только для настольного/студийного использования без наклона
   (v0.4-совместимость; перед 63 мм — не для игры «на коленях»).
4. **C** — нишевый: максимальный клин + встроенная 1S2P + подставка; печатать, если
   заказчик хочет автономность и сильный наклон и готов к 314 г / 20.8 ч.
   Батарейный отсек/крышку/подставку печатать отдельными деталями (см. prints.md).
