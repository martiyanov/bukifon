# Cost-down: где деньги и что делать с маржой

COGS P4 по rev.3 с микрофоном: **$241 / $215 / $196** (1/10/25). Цель $299 держится, но маржа
тонкая: gross на партии 10 — **28.1 %**, net ~18 %. Ниже — где стоимость и как её вернуть
без потери «народности».

## 2. Микрофонный узел: 1 405 ₽ ($17.6) — варианты

| Замена | Экономия | Риск |
|---|---:|---|
| **MEMS ICS-43434 → SPH0645LM4H** (footprint другой, но плата ещё не разведена) | ~80–120 ₽ | проверить L/R, чувствительность; зафиксировать footprint до PCB |
| **J16 IDC-6 + шлейф → JST-SH 6p + кабель** | ~90 ₽ | меньше ток/надёжность; шлейф короче |
| **TS5A23157 → 74LVC1G3157** (SPDT, дешевле) | ~60 ₽ | полоса/перекрёстные искажения — проверить |
| **MAX9814 → MAX4466 + внешний AGC?** | ~0–40 ₽ | MAX9814 с AGC удобнее; не экономить |
| Убрать 3.5 мм jack+MAX9814+TS5A (только MEMS) | **~680 ₽** | теряем «торчащий» микрофон/внешний вход — **не рекомендую** (R-37) |
| Закупка MEMS/ jack оптом (25+) | ~100–200 ₽ | нужен объём/срок |

**Реалистично:** −$2…3/шт без потери функций (MEMS, JST, mux). Убрать jack — не стоит: это
часть концепции «голос как вход».

## 3. Что даёт маржу

| Цена | Gross (партия 10) | Net | Комментарий |
|---|---:|---:|---|
| $299 | 28.1 % | ~18 % | цель; приемлемо для первой партии, но без запаса на брак/логистику |
| $319 | 32.6 % | ~22 % | +$20 почти не заметны покупателю |
| $349 | 38.4 % | ~28 % | комфортно; Full $399 |
| $399 Full | 23.3 % | ~13 % | bundle с картриджами/кейсом — пересчитать после cost-down |

**Рекомендация:** старт **$299** для первых 10–25 (репутация «народного»), с честной оговоркой
«цена первой партии»; после cost-down и P1-фиксации P4 — либо $319, либо $299 с доп. опциями
(батарея/кейс). Не поднимать выше $349 без улучшения звука/полифонии.

## 4. Cost-down план по приоритету

1. **P4**: сравнить модуль vs chip-down + адаптер (главные $18); если P1 PASS — зафиксировать.
2. **Дисплей**: альтернативные 5″ RGB565 (Raystar/GD) — сравнить цену/наличие.
3. **Микрофон**: MEMS SPH0645 + JST-SH + 1G3157 → −$2…3.
4. **Корпус**: печать партией 25 (22 ₽/г) vs 5 копий; B-light 231 г = ~5 100 ₽.
5. **Платы**: панелизация 3 в 1, заказ 10 комплектов, 2 oz только PWR-2.
6. **Сборка**: docs/72 RFQ; 5 прототипов → 25 (цена/точка падает).

## 5. Что не сокращать

- 42 клавиши/16 энкодеров/2 фейдера — это продукт;
- микрофон + jack, CV/GATE, 8×8 USB (P4), 10 джеков;
- тест-поинты/self-test 21, открытость, бумажные шаблоны.
