# Мгновенная запись (ресемплинг) и луппер

Решение заказчика: **в любой момент игры** записать звук синтезатора и сразу использовать
запись как сэмпл; многодорожечный луппер — в бэклог (после v1.0-rc).

## 1. Ресемплинг — обязательная функция v1.0-rc (R-29, D-83)

### Пользовательский сценарий

1. Играешь/играет секвенсор, звучит партия с эффектами.
2. Жмёшь **REC** (энкодер/кнопка) — запись начинается без остановки звука.
3. Жмёшь ещё раз — запись останавливается, сэмпл автоматически:
   - назначается на выбранный пэд/дорожку сэмплера и играется с клавиш;
   - получает имя `REC_<дата>_<номер>.wav` и сохраняется на SD;
   - может быть зациклен (loop) и обрезан по границам такта.
4. Результат можно сразу использовать в секвенсоре или выгрузить по USB (mass storage).

### Архитектура (P4, 32 МБ PSRAM, 48 кГц)

```
mix bus ──► master FX ──► limiter ──► I2S out
                          │
                          └─► record tap ──► ring buffer (PSRAM, 24-bit stereo)
                                                  │
                                     writer-задача (SD, вне audio-пути)
                                                  │
                                     sample pool (PSRAM) ──► sampler track/pad
```

- **Tap после master FX** (записываем то, что слышно, включая delay/reverb).
- **Кольцевой буфер** в PSRAM: 2 канала × 48 кГц × 3 Б. Лимиты: 8 с = 1.4 МБ, 30 с = 5.2 МБ,
  60 с = 10.4 МБ (влезает в 32 МБ вместе с 4 МБ pool и framebuffer).
- **Без аллокаций в audio-пути**: буфер выделяется заранее; tap только пишет.
- **Запись с точностью до сэмпла**: старт по next-block boundary, длина известна; latency
  компенсируется при назначении.
- **SD-запись** — отдельная задача/буфер: аудио-поток не блокируется; при медленной SD
  сэмпл остаётся в PSRAM, сохранение догоняет.
- **UI**: REC-индикатор в статус-баре, таймер, «REC → PAD 3»; отмена (undo) и перезапись.
- **Ограничения v1.0**: 16-bit/48 кГц моно или 24-bit стерео — по бюджету; предпочтение
  24-bit/48 кГц стерео (как запись с FX), длина ≤30 с на один сэмпл.
- **Квантизация**: опция «начать на границе такта» (для лупер-подобного использования).

### Критерии приёмки

| # | Тест | Критерий |
|---|---|---|
| 1 | REC во время 8-дорожечного воспроизведения | 0 xruns, max block ≤650 µs |
| 2 | Записанный сэмпл = слышимый звук | A/B по петле: разница ≤1 сэмпл, нет щелчка |
| 3 | Запись и сохранение на SD | 0 блокировок аудио; файл читается |
| 4 | Назначение на пэд/дорожку | играется с клавиш, loop/обрезка работают |
| 5 | 30 с запись | PSRAM не переполняется, UI отзывчив |

## 2. Многодорожечный луппер — бэклог (R-30, D-84)

Пользовательский сценарий: записать первую дорожку, она играет в цикле; поверх — вторую,
третью…; overdub, undo, mute/solo дорожек; синхронизация с транспортом и остальным
секвенсором; reverse/half-speed.

### Ограничения и бюджет памяти (P4)

| Параметр | Значение |
|---|---|
| Дорожек | 4–8 |
| Длина | 4–16 тактов (квантизация) |
| Формат | 24-bit/48 кГц стерео |
| Память | 8 дорожек × 8 тактов @120 BPM ≈ 8 × 16 с × 288 КБ/с ≈ **37 МБ** → **не влезает** |
| Реалистично | 4 дорожки × 8 тактов ≈ 18.4 МБ (влезает в 32 МБ PSRAM) или 8 × 4 такта |

Вывод: в v1.0-rc — **ресемплинг**; луппер — **v1.1** с 4 дорожками × 8 тактов или
потоковой записью на SD (медленнее, но без PSRAM-лимита).

### Что нужно продумать (backlog)

- квантизация длины и старта по тактам, метроном;
- overdub без накопления ошибки latency;
- undo последнего слоя (per-track history);
- reverse/half-speed (требует транспонирования/растяжения);
- синхронизация лупера с секвенсором (tempo map, bpm change);
- экспорт лупа на SD/по USB;
- UI: экран LOOPER с дорожками, REC/PLAY/UNDO, прогресс по тактам;
- кнопки: 42 клавиши используются как пэды лупера (тогда нужен режим LOOPER).

## 3. Влияние на железо/прошивку

- **PSRAM 32 МБ** (CORE-2) — обязательна для 30-секундного ресемплинга; S3-lite (8 МБ) —
  только короткие сэмплы (≤4 с) — ещё одна причина, почему первый SKU на P4.
- **SD** — 1-bit SDMMC достаточно (0.7+ МБ/с), но запись 24/48 стерео = 0.288 МБ/с — ок.
- **USB** — экспорт сэмплов через CDC/MSC (в v1.1).
- **Аудио-путь**: tap после master FX, без аллокаций, лимитер до/после — проверить на P1.
- **UI**: REC-кнопка в статус-баре, экран SAMPLER — пэды, LOOPER — новая страница (backlog).
