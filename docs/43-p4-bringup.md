# CORE-2 (P4) — bring-up чек-лист первой платы

> **Статус: PRE-FREEZE / DO NOT FABRICATE.** Порядок включения и измерения первой собранной
> CORE-2 rev.3 (P4-first). Ссылки: DFM/TP — `hardware/core2/dfm.md`, обзор — `docs/38`, план
> rev.3 — `hardware/core2/rev3-plan.md`. Не подавать питание на непроверенную сборку.

## 0. Подготовка

- Стенд: ЛБП 5 В/2 А с ограничением тока, DMM, осциллограф (≥100 МГц), USB-адаптер UART 3.3 В,
  кабель USB-C data, карта microSD, наушники/кабель loopback, PWR-2 (или VSYS 3.7 В/3 А).
- Плата: визуальный контроль (замыкания, полярность, FPC-40 ключ, 6×M3), прозвонка PGND/PWR.
- Прошивка: self-test из `hardware/core2/dfm.md` §2; логи — UART0 J4 115200 и/или USB CDC.
- TP: TP1–TP30 (см. `hardware/core2/dfm.md` §1); TP20 (BL_20V) — только щуп 100:1.

## 1. Порядок включения

| Шаг | Действие | Ожидание |
|---:|---|---|
| 1 | Визуал/DFM, прозвонка рельсов на КЗ (TP2/3/4/5/6/7/19/23/24/25) | нет КЗ, полярность верна |
| 2 | ЛБП 5 В, лимит 100 мА, подать на USB-C (или VBUS TP1) | ток покоя ≤50 мА, VSYS 3.0–4.4 В |

| 4 | UART0 J4 (115200): лог ROM/загрузчика | осмысленный лог, BOOT strap не активен |
| 5 | I2C-скан (0x57, 0x60/0x61, 0x20–0x23, 0x36 при подключённом PWR-2) | все адреса отвечают |
| 6 | C6 линк (esp-hosted): версия/скан Wi-Fi | ответ <100 мс |
| 7 | Аудио: I2S MCLK 12.288 МГц (TP9), loopback LINE OUT→AUDIO IN, 1 кГц | −6…−3 dBFS, SNR ≥80 дБ |
| 8 | RGB-дисплей: FPC-40, BL_PWM 50 %, тест-картинка | 800×480 без полос/битых; ≥15 fps full |
| 9 | SDIO: mount, запись/чтение 1 МБ | CRC ok, ≤50 мс |
| 10 | Панель: матрица 42, энкодеры 16, фейдеры, LED, INT | все, фантомов 0 |
| 11 | CV/GATE: loopback CV OUT→CV IN, GATE OUT→GATE IN | ошибка ≤±0.5 % FS |
| 12 | USB HS composite (HID+MIDI+UAC2+CDC), 30 мин | 0 drop/reconnect |
| 13 | PWR-2: подключить J17/J18, проверить +12/−12/+5/5V_LED/LED_RET, EN | рельсы по бюджету, PWR_GOOD ок |
| 14 | Self-test 20 (dfm.md §2) + soak 30–60 мин | все PASS, 0 xruns |
| 15 | Тепловой контроль: P4/PSRAM, MT3608 #3, BQ24074 | ≤70 °C (кроме BL) |

## 3. Типовые ошибки

| Симптом | Проверить |
|---|---|
| Нет boot/лога UART0 | BOOT strap (GPIO35/36), CHIP_PU, +3V3_MCU, PSRAM/модуль, TX/RX местами, 115200 |
| Нет C6 (scan fail) | +3V3_C6 (TP19), C6_RST (TP22), C6_CS (TP21), режим SPI, прошивка C6 |
| I2C пусто | подтяжки 2.2 к, адреса 0x57/0x60/0x61/0x20–0x23, J16/J18, питание панели |
| Нет звука / шум | MCLK (TP9), I2S BCK/LRCK (TP29/30), mute, AGND, PCM1808 VCC 5 В |
| Чёрный экран | FPC-40 ключ/ориентация, BL_PWM + BL_20V, pinout D-19, I2C панели (INT/DISP) |
| SD не монтируется | SDIO CLK/CMD/D0, +3V3, карта, SD_CD, длина линий |
| USB не enum | HS D+/D− (TP11/12) не перепутаны, USBLC6, CC 5.1k, VBUS-детект, кабель data |
| CV врёт | ref 1.65 В, I2C 0x60/0x61, TVS не греется, loopback |
| GATE не работает | GATE1 GPIO, 2N7000, подтяжка 4.7 к на +5, GATE_IN на панели |
| Brownout/reset при нагрузке | VSYS/ПБ, load-step, BQ24074 ILIM, тепло MT3608/MP1584 |
| Клавиши/энкодеры «плывут» | INT панели (J16.5), I2C 400 кГц, сканирование 500 Гц, фильтры 10 к/100 нФ |

## 4. Форма отчёта bring-up

`SN: ____  rev: ____  дата: ____  оператор: ____`
Шаги 1–15: PASS/FAIL + измеренные значения + фото/осциллограммы; для FAIL — гипотеза/действие.
Результат записать в EEPROM лог (offset 0x100, см. `hardware/core2/dfm.md` §3) и в issue.
