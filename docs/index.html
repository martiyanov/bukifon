Букифон / Bukifon

Открытый настольный синтезатор + сэмплер + платформа модулей. 3D-печатный корпус, открытые схемы KiCad, открытая прошивка C++.
Народный инструмент: комплект от ≤ $200 (S3) до ≤ $400 (полный с P4 и картриджами).

О проекте

Народный синтезатор — не лозунг, а требование к конструкции: один BOM, один набор STL, печатные шаблоны 1:1 и версии по SemVer, чтобы любой мастер или кружок мог собрать такой же инструмент. Открытые схемы, прошивка и геометрия — без заложников и облаков.

Букифон — это музыкальный инструмент-платформа, который собирается из доступных компонентов и печатается на обычном 3D-принтере. Идея в том, чтобы в одном корпусе совместить три мира: сэмплер в духе Elektron Digitakt, синтезатор в духе Elektron Syntakt и открытую платформу, для которой любой может писать свои модули — программные (C++/Lua) и аналоговые (картриджи на шине).

Проект полностью открыт: схемы в KiCad, прошивка на C++, параметрическая механика (STL/3MF), документация и правила версионирования. Название — от «буки» (вторая буква кириллицы) и греч. φωνή — «звук букв», «голос знаков».

Эргономика

Две половины клавиатуры Lapka-42 развёрнуты наружу (±18°), тамбы смотрят к центру, между ними — два 60-мм фейдера. Руки лежат как на пульте, а не на ноутбуке.

Звук

4 части, 8 голосов, 4-операторный FM, wavetable, ZDF-фильтры, лестница Муга (AS3320), характер Поливокса, 3D-мод-матрица на 16 слотов.

Секвенсор

Воркфлоу Elektron: p-locks, условия триггеров, микротайминг, звуковые локи, макросы и ctrl-all.

RF/дисплей

ESP32-P4 + ESP32-C6: Wi-Fi 6/BLE 5.3, RGB565/DSI 800×480, 32 МБ PSRAM, USB HS.

Клавиатура и DAW

Работает как USB-клавиатура: 42 клавиши Lapka-42 как печатная раскладка со слоями, 16 энкодеров как CC-контроллеры, transport. Плюс BLE-MIDI и BLE HID.

Модули

Шина 26-pin для аналоговых картриджей (VCO, фильтры, PT2399), программные модули через SDK и сменные деки ввода: 18 пэдов или 42 клавиши.

Три режима в одном корпусе

РежимЧто делает
Sampler8 дорожек (моно/стерео — по итогам бенчмарка), запись и импорт по USB-C/SD, срезы, гранулярность, insert-FX, p-locks. Класс Digitakt.
Synth8-голосный FM/wavetable, ZDF-фильтры, аналоговые модули на шине. Класс Syntakt.
HybridСэмплы как источники синтеза; общий секвенсор и мод-матрица для всех режимов.

    Честные ограничения

    Что инструмент не делает в v1.0-rc — до покупки, а не после: S3-lite — SPI-экран (10–20 fps partial) и стерео USB вместо 8×8; лупер и вокодер — v1.1; микрофон — для идей/битбокса/вокодера, не студийный вокал; батарея — опция, не в первой партии; p-lock CC — только внешние MIDI-треки (1 CC на шаг); Module API v0 — экспериментальный. Полный список — docs/76.

    FAQ

    Сколько стоит?

    Цель: P4 Standard $299 (Full $399), S3-lite $199. Пока не продаётся — ждём PWR 13/13, P1 и PCB rev.1 (docs/75).

    Можно собрать самому?

    Да: KiCad + C++ + STL + paperkit 1:1. Корпус B-light 231 г / 11.2 ч; мастерские — docs/72.

    Микрофон?

    Запись голоса → пэд, битбокс → шаги; вокодер v1.1. Аппаратный mute + LED.

    P4 или S3?

    P4 — RGB565/USB HS 8×8; S3-lite — SPI-экран и стерео USB. Решение после P1 (docs/56).

    Чем лучше Digitakt/Move?

    42 клавиши, 16 энкодеров, CV/GATE, микрофон, открытые схемы/прошивка/STL за $299 (docs/79).

    Как помочь?

    Пройти UX-тест (demo/?test=1), собрать по paperkit, предложить модуль, помочь с BOM/поставками.

    Бенчмарк (P1)

    Workload заморожен и измеряется переносимым харнессом: 8 голосов 4-оп FM + 8 granular-дорожек, PSRAM-поток, UI 800×480, USB UAC2 8×8. Критерий — max block ≤ 650 µs при дедлайне 1.333 мс и 24-часовой soak.

    Host-прогон: worst audio 218 µs (16.4 % дедлайна), все 7 сценариев PASS, 0 аллокаций в audio-path. Дальше — те же сценарии на ESP32-P4 и STM32H743 (devkit): только они дают вердикт по MCU.

    Модули и SDK

    Букифон — платформа: свои модули может писать каждый. Три вида расширений:

    Audio-rate (C++)

    Генераторы, эффекты, фильтры внутри аудио-колбэка. Module API v0: 10 функций, лимиты стека/состояния/времени, WCET-бюджет и автоматический bypass при перегрузке.

    Control-rate (Lua)

    Модуляторы, макросы, секвенсорные логики — безопасно, с лимитом инструкций и памяти.

    Аналоговый картридж

    VCO AS3340, фильтры LM13700/AS3320, PT2399 — на шине 26-pin, печатаемый корпус.

    SDK: Module API v0 · каталог модулей · валидатор · примеры: gain_fx (C++), lfo_module (Lua)
