### 1. Что за проект

**«Букифон» (Bukifon)** — открытый настольный синтезатор/сэмплер/секвенсор, который печатается
на 3D-принтере и собирается из доступных компонентов. Позиционирование: «народный инструмент» —
открытые схемы (KiCad, CERN-OHL-S-2.0), открытая прошивка (C++17, GPL-3.0-or-later), открытая
документация (CC-BY-SA-4.0) и модульность (аппаратные картриджи + софтовые модули).

**Железо (срез v0.57.0, 07.11.2025):**
- панель/корпус 380×210 мм, клин 8° (варианты A flat, B 8°, B-light 8° облегчённый, C 12°);
- **42 клавиши Lapka-42** (геометрия из upstream `braindefender/lapka-42`, отклонение 0.006 мм),
  **16 энкодеров EC11**, 5″ **800×480 RGB565**, 10 mini-jack, 2 фейдера 60 мм;
- **микрофон**: I2S MEMS ICS-43434 + 3.5 мм jack + MAX9814 AGC, аппаратный mute + LED;
- платы PRE-FREEZE: **CORE-2 rev.3** (ESP32-P4 + ESP32-C6, USB HS UAC2 8×8, 6 слоёв),
  **PANEL-2 rev.3** (4 слоя, 4× MCP23017, FPC-40, MEMS), **PWR-2 rev.1** (4 слоя 2 oz,
  TPS61088/LMR33630, BMS, MAX17048); ERC 0/0, 0/6w, 0/0;
- **PANEL-2 ∥ верхней панели** (0.00°, зазор 12 мм), оси энкодеров ⊥ панели;
- корпуса: A 301 г/19.9 ч, B 275.5/18.2, **B-light 228.9 г/11.0 ч**, C 313.2/20.7;
  все 11 задних вырезов + SD + USB-C; paperkit 1:1 (A3 или 4×A4).

**Прошивка (host, 407/407 тестов):**
- UI 7 вкладок (MAIN/SEQ/MIX/MOD/GEN/EXT/MIC), RU/EN + кириллица, зеркальная карта
  «ручка ↔ ячейка экрана»;
- 12 треков: 4 внутренних + 8 внешних MIDI (канал/PC/velocity/length, 1 CC p-lock, clock in/out);
- GEN: PROB/EUCLID/MUTATE/SCALE/ARP/EVOLVE/SEED; project v2 `.bkfp` с CRC32 и миграцией v1;
  storage backend A/B с recovery (power-cut/bit-flip);
- factory self-test **21** пункт (вкл. микрофон); **Module SDK v0.2** (манифест, loader с
  проверкой API/ABI/SHA до исполнения, 2 примера, упаковка);
- P4 bring-up app: I2C-скан 8/8, RGB565-паттерны, engine bench, MEMS; сборка IDF 5.5 —
  **369 552 Б**, factory 1 МиБ (65 % free), partitions/NVS.

**PCB rev.1 (в работе, до разводки):**
- 4 каркаса KiCad: CORE-2 200×108 6L, PANEL-2 две платы 180×190 4L, PWR-2 90×70 4L/2oz;
  контуры/крепёж/keepout, нетлист и футпринты (0 placeholder), **DRC 0/0**;
- fab dry-run (Gerber/Drill/CPL/BOM) — PASS, но **не для заказа**: 328 упрощённых падов,
  GND-полигоны не залиты; полная трассировка — после MCU freeze.

**Сайт/веб:** **https://bukifon.ru/** (HTTPS, канон; `.com` → 301), RU/EN, демо `/demo/`
(WebAudio, Web MIDI, микрофон, 4+8 треков, project v2, UX-тест 8 задач), раздел «Скачать»;
деплой на VDS, ежедневные бэкапы, TLS. Репозиторий: https://github.com/martiyanov/bukifon.

**Софт/бэклог (пока не реализовано):**
- **PWA-приложение** (полноценное, не демо): Web MIDI, микрофон, треки, WAV/stems export;
- **DAW-плагин**: VST3/AU + CLAP (JUCE 8), общий C++ движок, пресеты project v2;
- **софтовые модули `.bkm`**: machine/effect/generator/utility, установка SD→USB→Wi-Fi (C6
  web-UI), подпись Ed25519, sandbox (MPU/watchdog, лимиты), менеджер модулей;
- лупер и вокодер — v1.1.

### 3. Текущий статус

Инженерная часть, софт и документация закрыты настолько, насколько возможно без железа.
**v1.0-rc не достигнут** — нужны физические шаги: заказ стендов, печать B-light, пересоздание
репозитория; затем PWR 13/13 → P1-замеры P4 vs H743 → MCU freeze → трассировка/PCB rev.1 →
3–5 прототипов → RC DoD + UX-тест 5 людей.

Проверки: `check_all` 8/8, security clean, 407 тестов, DRC 0/0, сайт 200, ссылки 691/0 битых.
