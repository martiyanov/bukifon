## 4. Критичные цепи

- **USB HS** (CORE-2): дифф-пара 90 Ω, без стабов, ESD у разъёма, длина <40 мм.
- **I2S/DAC** (CORE-2): MCLK/BCK/WS параллельно, экран GND, аналоговые выходы после DAC —
  отдельная зона, без пересечения с DC-DC.
- **Микрофон** (PANEL-2/CORE-2): MIC_BCK/WS/DATA — короткие, экранированные, I2S1 J16↔J19 1:1;
  MIC_VDD через FB, отдельная земля MIC звездой.
- **LED-цепочка** (PANEL-2): LED_DATA 3.3 В, последовательно 17×WS2812, буфер/уровни, ток ≥1.5 А
  по 5V_LED, возврат LED_RET отдельно от аудио GND.
- **CV/GATE**: MCP4728 → джеки, RC-фильтр, защита; CV IN — TVS, делитель.

## 5. DRC/DFM-правила (минимум)

- зазор/трасса: 6/6 mil (сигнал), 8/8 mil (питание), 10 mil (класс), 0.2 мм к краю;
- переходные: 0.3/0.6 мм (сигнал), 0.45/0.8 мм (питание), термо-барьеры;
- шёлкография: ≥0.15 мм, не на падах; полярность/позиционные обозначения;
- паяльная маска: 0.1 мм зазор; тест-поинты φ1.0 мм (TP1–TP32 CORE-2, TP36–39 PANEL-2);
- отверстия/пазы по краю — фрезой ≥1 мм, радиусы ≥0.5 мм;
- **fiducials** 3×1 мм по углам + tooling holes; panelization ≤220×220 для домашней печати.

## 6. Пошаговый процесс (после freeze)

1. Импорт netlist из `.kicad_sch`; создать `.kicad_pcb` с контуром/крепёжом.
2. Floorplan по §3; критичные цепи — первыми, затем питания, затем сигнал.
3. Заливки GND (4 слоя), проверка возвратных токов; аналог/цифра — звезда.
4. DRC + ERC-чеклист; проверка DFM (docs/38) и test points.
5. Импеданс-отчёт (USB) и stackup от фабрики.
6. Ревью: Lead + внешний (по возможности); фото/скриншоты; чек-лист.
7. Gerber/Drill/CPL → `fab/` по [docs/83](83-fab-package.md); заказ только после gate.

## 7. Риски

- P4 BGA/модуль и USB HS — главный риск первой платы; при возможности — 4 слоя для USB-зоны.
- PANEL-2 360×190 (две платы 180+180): прогиб/панелизация; жёсткость 1.6 мм, 6×M3.
- PWR-2 2 oz: минимальные зазоры; тепловой расчёт TPS61088 (docs/44).
- Микрофон: акустика/изоляция от LED — проверять на прототипе (docs/71).
