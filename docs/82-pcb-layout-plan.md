# План разводки PCB rev.1 (CORE-2 / PANEL-2 / PWR-2)

Документ-«мостик» между PRE-FREEZE-схемами и разводкой. Разводка начинается **только после**
MCU freeze (docs/56) и PWR 13/13 (docs/51); до этого — подготовка правил и посадочных мест.

## 1. Стек и материалы

| Плата | Слои | Стек | Толщина | Медь | Примечание |
|---|---|---|---|---|---|
| CORE-2 | 6 | Sig / GND / Sig / PWR / GND / Sig | 1.6 мм | 1 oz (внутр. 0.5 oz) | USB HS 90 Ω, I2S, аудио |
| PANEL-2 | 4 | Sig / GND / PWR / Sig | 1.6 мм | 1 oz | 380×210-контур, 42 клавиши, FPC-40 |
| PWR-2 | 4 | Sig / GND / PWR / Sig | 1.6 мм | **2 oz** | 1.6 А + батарея, тепловые полигоны |
| CORE-S3 (lite) | 4 | Sig / GND / PWR / Sig | 1.6 мм | 1 oz | отдельный профиль |

Импеданс: USB HS D+/D− — **90 Ω ±10 %** (дифф.), USB FS — 90 Ω; I2S/SPI — без импеданса,
но длина <50 мм; PSRAM/Flash — короткие трассы, без стабов.

## 2. Контуры и крепёж

- Контуры плат берутся из механики (fitcheck v0.5: внутренние габариты корпуса, стойки).
- PANEL-2: 6×M3 по механике PANEL-1 rev.2 — **(30/145/260 × 30/180) мм** + 2 дополнительных
  под экран/клавиши; панель 380×210, режется на две половины (193+190) по шипу.
- CORE-2/PWR-2: контур = внутренняя ниша корпуса минус стойки; точные координаты — из
  `mechanical/stl_v05_B_light` (после согласования с mechanical), не «на глаз».
- Все отверстия — в `spec/panel-spec-v0.4.json` (панель) и `mechanical/fit_check.md` (корпус).

## 3. Зоны размещения (floorplan)

| Плата | Зоны | Правила |
|---|---|---|
| CORE-2 | USB-C (край), P4+C6 (антенна ≥15 мм), PSRAM, DAC/ADC (аналог), PCM5102A/1808, BMS/заряд, SD | аналог отдельной зоной, звезда GND; C6-антенна на краю, keepout под ней; USB HS пары до разъёма без переходных отверстий |
| PANEL-2 | 42 Choc, 16 EC11, 10 джеков, фейдеры, FPC-40, MCP23017×4, MEMS (122,5.5), LED-цепочка | клавиши/энкодеры по JSON ±0.1 мм; MEMS ≥10 мм от WS2812/BL; FPC-40 — прямой выход, без резких изгибов |
| PWR-2 | TPS61088 + индуктивность, LMR33630, BMS, батарейный разъём, master switch | тепловые полигоны, силовые трассы ≥2 мм (2 oz), обратная связь отдельно, TVS у разъёмов |

## 4. Критичные цепи

- **USB HS** (CORE-2): дифф-пара 90 Ω, без стабов, ESD у разъёма, длина <40 мм.
- **I2S/DAC** (CORE-2): MCLK/BCK/WS параллельно, экран GND, аналоговые выходы после DAC —
  отдельная зона, без пересечения с DC-DC.
- **Микрофон** (PANEL-2/CORE-2): MIC_BCK/WS/DATA — короткие, экранированные, I2S1 J16↔J19 1:1;
  MIC_VDD через FB, отдельная земля MIC звездой.
- **LED-цепочка** (PANEL-2): LED_DATA 3.3 В, последовательно 17×WS2812, буфер/уровни, ток ≥1.5 А
  по 5V_LED, возврат LED_RET отдельно от аудио GND.
- **CV/GATE**: MCP4728 → джеки, RC-фильтр, защита; CV IN — TVS, делитель.

## 5. DRC/DFM-правила (минимум)

- зазор/трасса: 6/6 mil (сигнал), 8/8 mil (питание), 10 mil (класс), 0.2 мм к краю;
- переходные: 0.3/0.6 мм (сигнал), 0.45/0.8 мм (питание), термо-барьеры;
- шёлкография: ≥0.15 мм, не на падах; полярность/позиционные обозначения;
- паяльная маска: 0.1 мм зазор; тест-поинты φ1.0 мм (TP1–TP32 CORE-2, TP36–39 PANEL-2);
- отверстия/пазы по краю — фрезой ≥1 мм, радиусы ≥0.5 мм;
- **fiducials** 3×1 мм по углам + tooling holes; panelization ≤220×220 для домашней печати.

## 6. Пошаговый процесс (после freeze)

1. Импорт netlist из `.kicad_sch`; создать `.kicad_pcb` с контуром/крепёжом.
2. Floorplan по §3; критичные цепи — первыми, затем питания, затем сигнал.
3. Заливки GND (4 слоя), проверка возвратных токов; аналог/цифра — звезда.
4. DRC + ERC-чеклист; проверка DFM (docs/38) и test points.
5. Импеданс-отчёт (USB) и stackup от фабрики.
6. Ревью: Lead + внешний (по возможности); фото/скриншоты; чек-лист.
7. Gerber/Drill/CPL → `fab/` по [docs/83](83-fab-package.md); заказ только после gate.

## 7. Риски

- P4 BGA/модуль и USB HS — главный риск первой платы; при возможности — 4 слоя для USB-зоны.
- PANEL-2 380×210: прогиб/панелизация; жёсткость 1.6 мм, 6×M3.
- PWR-2 2 oz: минимальные зазоры; тепловой расчёт TPS61088 (docs/44).
- Микрофон: акустика/изоляция от LED — проверять на прототипе (docs/71).
