## 3. Порядок действий (следующие 2 недели при заказе «завтра»)

1. **День 1**: заказ G1+G2+G3; печать G4; пересоздание репо G12.
2. **Дни 2–7**: приход EVM → 13 измерений (2.5 дня) → G5; приход P4 EV → hello/I2C/engine/bench → G6.
3. **Дни 7–10**: MCU freeze (G7); если P4 проходит — PCB rev.1 дизайн; если нет — fallback H743.
4. **Дни 10–21**: заказ PCB+stencil (G8), сборка 3–5 прототипов (G9, docs/72).
5. **Дни 21–28**: bring-up (docs/43), factory self-test 21, RC DoD (G10), UX-тест 5 людей.
6. **Релиз v1.0-rc**: bundle, тег, сайт, отчёт (G11).

## 4. Точки stop/go

- **PWR**: любой FAIL в T3/T4/T5/T6 → фикс макета и повтор, **PCB не заказывать**.
- **P1**: max block >650 µs или UI <30 fps у P4 → H743-ветка (CORE-2-H743), P4 — в lite.
- **Сборка**: first-pass yield <80 % на 5 прототипах → правка DFM/сборки до партии.
- **UX**: <4/5 проходят time-to-sound ≤10 с → правки UI до релиза.
