# UX-тест интуитивности (веб-харнесс, blind)

Цель — измерить, насколько быстро новый человек получает результат (docs/68 §метрики),
без подсказок и без участия автора. Харнесс встроен в демо:

**Ссылка для теста:** https://martiyanov.github.io/bukifon/demo/?test=1
(работает и локально: `python3 -m http.server -d docs` → `/demo/?test=1`).

## 1. Как проходит

1. Участник открывает ссылку **один раз**, без инструкций (blind).
2. На экране — задача 1/8 и таймер; задача засчитывается **автоматически** при правильном
   действии; харнесс сам переходит к следующей.
3. В конце — результаты по задачам (секунды), кнопка **COPY JSON** → прислать в чат проекта.
4. Никаких подсказок в интерфейсе нет; ведущий только читает вводную: «пользуйтесь как
   инструментом, делайте что написано».

## 2. Задачи (8)

| # | Задача | Что проверяет | Порог (docs/68) |
|---|---|---|---|
| 1 | Получи звук (клавиши / PLAY / MIC) | time-to-sound | ≤10 с |
| 2 | Открой страницу ENV | L2 ≤1 жест | ≤2 с |
| 3 | Замьють две партии | mute/партии | ≤3 с |
| 4 | Создай евклидов ритм (GEN → EUCLID) | L3 ≤2 жеста | ≤8 с без инструкции |
| 5 | Сделай MUTATE и верни (UNDO) | обратимость | 100 % находят UNDO |
| 6 | Запиши выход на пэд (REC) | запись без потерь | 0 случайных стираний |
| 7 | Переключи фейдеры в SCENE | режимы фейдеров | ≤2 с, без скачка |
| 8 | Вернись в MAIN одним жестом (HOME) | HOME | ≤1 с |

## 3. Кого тестировать

Минимум **5 человек**, не знакомых с проектом; желательно: 1 опытный музыкант, 1 новичок,
разный рост/зрение (40–60 см до экрана), хотя бы один — на ноутбуке и один — на телефоне.

## 4. Метрики и приёмка

- `time-to-sound ≤10 с` — 5/5;
- `time-to-idea` (задачи 2–6 подряд) ≤30–40 с суммарно;
- **0 критических ошибок** за первые 5 минут (не та партия/страница/режим);
- задачи 5–8 — 100 % (иначе интерфейс не «интуитивен», а «запоминаем»);
- оценить субъективно 1–5 в конце (опционально, в комментарии JSON).

## 5. Приватность

- Всё считается **локально в браузере**; JSON копируется вручную.
- Никаких записей звука/микрофона в тесте; MIC-задача только включает вход (WebAudio) и
  не отправляет данные.
- Имя/контакты не нужны; в JSON только даты/времена задач.

## 6. Что делать с результатами

1. Собрать 5+ JSON, свести в таблицу (task → медиана/разброс).
2. Всё, что >порога — кандидат на правку UI (docs/61/65), обновить docs/68/69 и релиз.
3. Повторный тест после правок — сравнить медианы (цель: 9–10/10 по рубрике docs/65).
4. Результаты хранить в `docs/reviews/ux-test-<date>.md` (без персональных данных).
