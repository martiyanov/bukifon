## 3. Порядок заказа

1. Сначала **1–4 + 5–6** (ядро стенда) — можно тестировать host-бенч на железе.
2. Потом **7–8** (питание/нагрузка) — для P2 и питания PWR-2.
3. Дисплей (12) — **после фиксации MPN** (O-15: FPC-40 pinout) и решения RGB vs DSI.
4. S3 (11) — параллельно, для «народной» CORE-S3.

## 4. Что проверить сразу после распаковки

- платы определяются (esptool/STM32CubeProgrammer), PSRAM видна;
- I2S loopback PCM5102A→PCM1808 (синус 1 кГц);
- USB HS на P4/H743 (lsusb, скорость 480);
- замер тока покоя каждой платы;
- зафиксировать серийники и версии чипов в `docs/05-benchmark-workload.md` (раздел platform).

- Заказ делает владелец проекта (доступ к оплате/доставке).

- После замеров — заполнить таблицу решения в docs/26 §5 и зафиксировать MCU в spec/90.
