# Веб-демо Букифона (интерактивная модель интерфейса)

Цель — дать будущему пользователю **потрогать интерфейс и звук до покупки/сборки**:
секвенсор, 16 энкодеров, 42 клавиши, фейдеры, джеки и 4 режима.

**Демо:** https://martiyanov.github.io/bukifon/demo/ (исходники — `docs/demo/`).
Запуск локально:

```bash
python3 -m http.server 8000 -d docs
# открыть http://localhost:8000/demo/
```

## Что можно попробовать

| Элемент | Действие |
|---|---|
| 42 клавиши (2×21, Lapka-42) | клик/палец, QWERTY (`A W S E D F T G Y H U J K O L P ;`) |
| 16 шагов × 4 партии | клик по шагу — включить/выключить, акцент на 1/5/9/13 |
| 8 энкодеров на экран | тянуть вверх/вниз: cutoff, resonance, env, drive, ADSR |
| 2 фейдера | мастер-громкость и глубина delay |
| 10 джеков | клик — «воткнуть кабель» (визуально) |
| Режимы | SYNTH / SAMPLER / DAW / USB-KBD — разные экраны |
| Транспорт | PLAY/STOP, BPM, SPACE |
| Внешняя MIDI-клавиатура | Web MIDI, подключается автоматически |

## Звук

Упрощённый **2-оп FM** (WebAudio): 4 партии со своими настройками, 24 голоса max, ADSR,
lowpass-фильтр, delay, компрессор. Это не прошивка: реальный движок — 4-оп FM + wavetable +
SVF/ZDF на ESP32-P4, 8 стерео-дорожек, 32 МБ PSRAM.

## Ограничения демо (честно)

- сэмплер и DAW — схематичные экраны, без реального SD/CC;
- нет CV/GATE, модулей, сохранения проектов;
- звук упрощён; нет 8×8 USB-аудио;
- UI — веб-реплика по скриншотам из `firmware/artifacts/ui/`, а не сам firmware.
