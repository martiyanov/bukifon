# Букифон: дорожная карта

Обозначения: **P0** — уже сделано, **P1…P6** — этапы. Сроки — для одного занятого
разработчика; параллельная работа нескольких людей сокращает.

## Текущее состояние (P0, сделано)

- Панель **v0.4**: 380 × 210 × 3 мм, 42 клавиши Lapka-42 (точная геометрия, ±18°),
  16 энкодеров, экран 5.0″ 800×480 без рамки, 10 mini-jack, 2 фейдера, 0 пересечений.
  Канон: `spec/panel-spec-v0.4.json`, шаблон 1:1: `renders/templates/bukifon_v04_panel_1to1.pdf`.
- Корпус **v0.4**: 380 × 210 × 63 мм, 6 деталей, watertight, печать без поддержек,
  панель режется 193 + 190 мм с шипом, 83 выреза, fitcheck 0 конфликтов.
- Схемы v1.0 (CORE-1, PANEL-1, деки, 5 аналоговых модулей, PWR-BATT-1), ERC 0 ошибок.
- Прошивка-прототип на RP2040: движок, host-тесты 67/67, UF2 собирается.

## P1. Выбор платформы и стенд (2–3 недели)

**Цель:** подтвердить цифры из `docs/11-esp32-feasibility.md` на реальном железе.

- [ ] Devkit: ESP32-S3-DevKitC-1 (8 МБ PSRAM) + PCM5102A + PCM1808 + дисплей 800×480 RGB.
- [ ] Стенд: 4 энкодера, 12 клавиш, 2 джека, SD-карта.
- [ ] Замеры: задержка I2S (двойная буферизация), загрузка CPU на 8 голосах FM,
      скорость PSRAM→SRAM→I2S, fps экрана, USB-MIDI/audio.
- [ ] Решение: S3 (v1.0) или сразу P4 (v1.1). Результат — в `docs/11` раздел «замеры».

**Выход:** таблица «задача → % CPU/RAM», решение по MCU, зафиксированный BOM стенда.

## P2. Электроника rev.3 (3–4 недели)

- [ ] CORE-3: сменный модуль MCU (S3 или P4), PSRAM, microSD, USB-C (данные + заряд),
      PCM5102A + PCM1808, 2× MCP4728, MCP3208, шина модулей 26-pin, защита питания.
- [ ] PANEL-2: 16 энкодеров (2× MCP23017), матрица 42 клавиш (6×7), LED, экран RGB,
      джеки, фейдеры.
- [ ] PWR-2: 1S2P 18650 или LiPo 5000 мА·ч, TP4056/MP1584, BMS, заряд по USB-C.
- [ ] ERC 0 ошибок, netlist-проверки, BOM с ценами и наличием.

**Выход:** 3 платы (CORE-3, PANEL-2, PWR-2) в KiCad + герберы + BOM; заказ пробной партии (5 шт).

## P3. Прошивка: синтезатор MVP (4–6 недель)

- [ ] Порт DSP-движка на выбранный MCU (float, SIMD где есть).
- [ ] 4 части × 8 голосов, 4-оп FM + wavetable, ZDF-фильтры, 3D-мод-матрица 16 слотов.
- [ ] UI 800×480: главный экран, 16 энкодеров, меню, клавиатура.
- [ ] Секвенсор: 16 шагов × 4 части, p-locks, условия, микротайминг, макросы, ctrl-all.
- [ ] MIDI TRS + USB-MIDI, CV/Gate out (MCP4728), сохранение проектов на SD.

**Выход:** инструмент играет полифонический синтез, секвенсор работает, проект
сохраняется/загружается; автотесты DSP (host) + тесты на железе.

## P4. Прошивка: сэмплер MVP (4–6 недель)

- [ ] Запись с PCM1808 (моно/стерео), импорт WAV с SD/USB, срезы, базовая нормализация.
- [ ] 8 (S3: 4–6) стерео-дорожек: воспроизведение, loop, реверс, pitch (без stretch).
- [ ] Упрощённый time-stretch (WSOLA) — как опция.
- [ ] 1–2 insert-FX на дорожку (фильтр, decimator, reverb/delay send).
- [ ] Режимы Sampler / Synth / Hybrid: общий секвенсор и мод-матрица.

**Выход:** демо-трек: сэмплы + синтез в одном проекте, без глитчей при 8 дорожках
(S3 — при 4–6), задержка < 15 мс.

## P5. SDK модулей и сообщество (4–6 недель)

- [ ] **Программный модуль**: C++ `BukifonModule` (init/process/params/ui), статическая
      регистрация или загрузка с SD; шина параметров; примеры (реверб, грануляр).
- [ ] **Скриптовый слой**: Lua-модули для простых генераторов/модуляторов (безопасный
      запуск, лимиты по времени/памяти).
- [ ] **Аналоговый картридж**: спецификация шины 26-pin (питание ±12 В, CV, gate, audio),
      формат платы, шаблон корпуса, CARTRIDGE.md, пример «VCO на AS3340».
- [ ] **Сменная дека**: EEPROM-идентификация (24C32), автоподхват раскладки (18 пэдов /
      42 клавиши / 16 пэдов).
- [ ] Документация: «напиши свой модуль за вечер», шаблоны, каталог модулей, лицензии.

**Выход:** 3 примера модулей (1 C++, 1 Lua, 1 аналоговый) + SDK-документация.

## P6. Производство и релиз v1.0 (4–6 недель)

- [ ] Финальный корпус: сборка, крепёж, кабели, изоляция, вентиляция.
- [ ] Печать гайда сборки (docs/02-build-guide), фото/видео, проверка на 5 экземплярах.
- [ ] BOM с ценами: цель ≤ 400 $ за комплект (без учёта печати).
- [ ] Лицензии: аппаратура CERN-OHL-S-2.0, прошивка GPL-3.0, документация CC BY-SA.
- [ ] Релиз: GitHub-репозиторий, тег v1.0, герберы, STL/3MF, прошивка, инструкции.

**Выход:** 5 собранных экземпляров, публичный релиз, инструкция сборки, BOM.

## P7 (после v1.0). Развитие

- ESP32-P4 / двухчиповая версия (S3 + DSP) — полный 8-дорожечный сэмплер.
- USB audio class 2 (8 каналов), Overbridge-подобный редактор.
- Беспровод: Wi-Fi модуль (ESP32-C6) для передачи проектов.
- Аналоговые модули: VCO AS3340, фильтр LM13700, лестница AS3320, PT2399 —
  перевести с макетов на платы с панелью.

## Риски и как снимать

| Риск | Вероятность | Смягчение |
|---|---|---|
| S3 не тянет 8 стерео-дорожек | высокая | v1.0: 4–6 дорожек; P4 в v1.1 |
| PSRAM-латентность в звуке | средняя | двойная буферизация, блоки 1–4 КБ, звук в SRAM |
| Дисплей 800×480 тормозит | средняя | 30 fps, частичная перерисовка, потом RGB-параллель/P4 |
| SDK-модули ломают реалтайм | средняя | лимиты, watchdog, Lua-песочница, модуль в отдельном ядре |
| Дорогие/недоступные чипы | низкая | аналоги (STM32H7/Teensy) как запасной путь |
| Габарит/эргономика | низкая | панель 1:1 уже напечатана и проверена |

## Критический путь

`P1 (платформа) → P2 (платы) → P3 (синтез) → P4 (сэмплер) → P6 (релиз)`;
`P5 (SDK)` можно вести параллельно с P4 после стабилизации API движка.
