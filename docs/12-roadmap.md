# Букифон: дорожная карта (обновлена по итогам второго мнения)

Порядок этапов изменён по ревью [docs/03-second-opinion-mcu.md](03-second-opinion-mcu.md):
сначала **бенчмарк и сведение требований**, только потом плата rev.3. Причина: три спеки

**P0** — сделано: панель и корпус v0.4 (380×210×63, 42 клавиши ±18°, 83 выреза,

---

## P1. Бенчмарк платформ (2 недели) — первый шаг

Заказать devkit: **ESP32-P4** (32 МБ PSRAM), **ESP32-S3** (8 МБ), **STM32H743** (Nucleo-H743ZI2).

Замеры (не memcpy, а реальные паттерны):
- [ ] гранулярное чтение PSRAM (линия 64 Б, 8–16 сэмплов) — МБ/с и промахи кэша;
- [ ] фреймбуфер 800×480: полная и частичная перерисовка, fps (SPI vs DSI/LTDC);
- [ ] аудио-блок 64 сэмпла @48 кГц: 8 голосов FM + 8 дорожек, % CPU, xruns/час;
- [ ] USB audio: UAC2 стерео и 8 каналов (P4/H7 — HS; S3 — FS);
- [ ] задержка I2S in→out (цель ≤ 6 мс).

**Критерии выхода:** таблица «платформа × задача → % CPU / МБ/с / fps / xruns»,
решение по MCU. **Без этого не заказывать платы.**

## P2. Сведение требований и cut-list (2 недели)

- [ ] единый реестр требований `spec/90-requirements-registry.md` — единственный источник;
- [ ] обновить устаревшие `spec/20`, `spec/40`, `README.md`, `firmware/README.md`
      (там ещё 315×145, 8 ручек, 2.8″ экран);
- [ ] подписанный **cut-list**: 8 стерео → **8 моно**, 2 insert → **1 insert + 2 send**,
      time-stretch → только гранулярный, экран 30 fps с частичной перерисовкой;
- [ ] зафиксировать интерфейсы: панель, шина модулей, формат проекта, SDK-ABI.

**Критерии выхода:** один набор чисел на весь проект; cut-list подписан; изменения
внесены в спеки.

## P3. Аудио-ядро на devkit (8–10 недель)

- [ ] 8 голосов 4-оп FM + wavetable + ZDF-фильтры + лестница (AS3320 позже);
- [ ] 8 моно-дорожек сэмплера (гранулы), 1 insert + 2 send;
- [ ] 48 кГц, блок 64; **0 xruns/час, CPU ≤ 70 %, latency ≤ 6 мс**;
- [ ] USB audio (UAC2 по возможностям платформы), MIDI TRS + USB-MIDI.

**Критерии выхода:** демо-трек 8 дорожек + 8 голосов без глитчей; замеры в docs/11.

## P4. Панель и I/O на devkit (4 недели, параллельно с P3)

- [ ] 16 энкодеров (2× MCP23017), матрица 42 клавиш 6×7, LED;
- [ ] экран 800×480 (интерфейс по макету v0.4), 10 джеков, 2 фейдера, 4 винта;
- [ ] CV out (MCP4728), CV in (MCP3208), gate.

**Критерии выхода:** стенд с полной панелью, все элементы читаются/рисуются.

## P5. Электроника rev.3 (6–8 недель) — после бенчмарка

- [ ] CORE-3: выбранный MCU, PSRAM, microSD, USB-C, PCM5102A + PCM1808, 2× MCP4728,
      MCP3208, шина 26-pin, защита питания;
- [ ] PANEL-2: 16 энкодеров, 42 клавиши, экран, джеки, фейдеры;
- [ ] PWR-2: 1S2P 18650 / LiPo 5000 мА·ч, BMS, заряд USB-C;
- [ ] ERC 0, netlist-проверки, BOM, герберы.

**Критерии выхода:** 3 платы, заказана пробная партия 5 шт.

## P6. MVP (10–12 недель)

- [ ] Sampler / Synth / Hybrid, общий секвенсор и 3D-мод-матрица;
- [ ] save/load проектов, сэмплы с SD, базовый набор пресетов;
- [ ] базовый SDK: статические C++-модули (аудио-рейт), Lua (control-rate).

**Критерии выхода:** инструмент играет, сохраняет проекты, 3 примера модулей.

## P7. Пилот 10–20 шт (4–6 недель)

- [ ] сборка 10–20 экземпляров, фото/видео, отладка гайда;
- [ ] BOM и цены, упаковка, лицензии (CERN-OHL-S, GPL-3.0, CC BY-SA).

**Критерии выхода:** 10–20 работающих экземпляров, публичный релиз v1.0.

## P8. SDK сообщества (после пилота)

- [ ] SDK-документация, шаблоны, песочница Lua, аналоговые картриджи, сменные деки;
- [ ] каталог модулей, примеры, CI-проверки модулей.

## Риски (из ревью)

| Риск | Проявление | Смягчение |
|---|---|---|
| **Спека противоречива** | 4 ревизии панели, 3 габарита, 8↔16 энкодеров, 2.8″↔5″ | реестр требований + подписанный cut-list (P2) |
| **Память/шина** | PSRAM + кэш + фреймбуфер + USB на одном MSPI | запас 2×, DSI/LTDC, звук в SRAM, замеры (P1) |
| **Аналог/механика** | 42 клавиши + 16 энкодеров + 5″ + 10 джеков в 63 мм; ±12 В; AS3320 DIP-18 | плоский прототип, замер шума до корпуса |
| Не хватит P4 | 8 стерео + 8 голосов + UAC2 | cut-list; второй MCU как voice expander по I2S |
| Дорогой P4 | $10–15/шт | H743 как альтернатива; S3 как «лайт» |

## Критический путь

`P1 бенчмарк → P2 требования/cut-list → P3 аудио-ядро → P5 rev.3 → P6 MVP → P7 пилот → P8 SDK`.
`P4 (панель)` идёт параллельно с P3.
