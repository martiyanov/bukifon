# Микрофон и голос как вход: запись, битбокс, вокодер

Идея: **голос — самый быстрый вход musical idea**. Пропеть/настучать идею и сразу получить
сэмпл, паттерн или (позже) вокодер. Микрофон — не «опция для студии», а часть инструмента,
всегда доступная, с честной приватностью (кнопка mute + LED).

## 1. Сценарии

| # | Сценарий | Версия |
|---|---|---|
| 1 | **Записать голос/фразу** в любой момент → сэмпл на пэд, обрезка, loop | v1.0-rc |
| 2 | **Битбокс → паттерн**: настучать «кик/снейр/хэт» → шаги секвенсора (простые классы) | v1.0-rc (onset/velocity), классы — v1.1 |
| 3 | **Вокодер**: голос управляет синтезатором (8–16 полос) | v1.1 (backlog R-39) |
| 4 | Пение в реальном времени как модулятор/экспрессия | v1.2 |

## 2. Аппаратно

### Микрофон
- **Основной: цифровой I2S MEMS-микрофон** (ICS-43434 / SPH0645LM4H) на PANEL-2,
  верхняя кромка, акустический порт с сеткой/поролоном; 24 бит/48 кГц, без аналогового шума.
- **Дополнительный: 3.5 мм TRS jack** (mic/headset) на задней панели CORE-2 для
  петлички/гусиной шеи: электрет → **MAX9814** (AGC, 20–60 дБ) → аналоговый коммутатор →
  PCM1808 (line-in) или отдельный вход. Питание микрофона 3.3 В через bias-резистор 2.2 кОм.
- **«Торчащий» микрофон**: гибкая гусиная шея на 3.5 мм — вставляется в mic-jack, крепится
  клипсой к корпусу; либо короткий жёсткий держатель на верхней кромке (печатная деталь).
- **Приватность (обязательно)**: аппаратный **mic mute switch** (переключатель, разрывающий
  питание/сигнал) + **LED «MIC ON»**; в прошивке — индикатор и запрет записи при mute;
  никакой постоянной передачи звука наружу (Wi-Fi/BT) без явного действия.

### Маршрут сигнала
```
MEMS I2S ──────────────► P4 I2S1 (RX)
3.5mm → MAX9814 AGC ───► PCM1808 IN (L/R) ──► P4 I2S0 (RX)
                                    └─► (v1.1) вокодер: голос = модулятор,
                                        внутренний синтез = несущая
```
- I2S1 на P4 отдельный от аудио-кодека; при необходимости — TDM (mic + codec).
- Задержка: mic→P4 ≤ 5 мс (I2S DMA), для вокодера — компенсация.

### Механика
- Отверстие Ø1.5–2 мм + сетка на верхней кромке PANEL-2 (центр или слева от экрана),
  звуковод к MEMS; защита от влаги/пыли.
- Клипса/держатель для гусиной шеи — печатная деталь (B-light), не мешает панели.
- Все вырезы — из `spec/panel-spec-v0.4.json` + новые (mic port), fitcheck обновить.

## 3. Прошивка

| Блок | Что |
|---|---|
| Capture | I2S1 RX, ring buffer 2×N, VAD (порог/AGC), 24/48 |
| Record | запись в PSRAM → сэмпл → пэд/SD (как REC, docs/63), авто-обрезка тишины |
| Beatbox | onset detection (энергия+производная), классификация v1: low/mid/high → kick/snare/hat; velocity → акцент; заполнение шагов с квантизацией |
| Vocoder (v1.1) | 8–16 полос (biquad/FFT), огибающие голоса → усиление полос несущей; formant/vocoder presets |
| UI | страница **MIC**: SOURCE (LINE/MIC), GAIN, THRESH, MONITOR, BEATBOX (on/off + чувствительность), REC → PAD |
| Приватность | MUTE switch → LED; индикатор в контекст-строке; запрет записи при mute |
| Сохранение | mic-настройки в проекте/пресете; сэмплы — как обычные |

## 4. UX (в духе docs/68)

- **L1**: кнопка REC + источник; уровни/индикатор всегда в статусе (маленький).
- **L2**: страница MIC (source/gain/thresh/beatbox/monitor) — один жест.
- **Быстрый сценарий «идея за 10 секунд»**: включил → MIC → REC → спел/настучал → PAD/шаги →
  играешь. Никаких меню.
- **Битбокс**: включил BEATBOX, выбрал партию, настучал — шаги заполнились; UNDO откатывает.
- **Вокодер** (v1.1): GEN/страница VOCODER: несущая (партия), полосы, formant, mix; голос
  управляет фильтрами в реальном времени.

## 5. Требования и критерии приёмки

| # | Требование | Критерий |
|---|---|---|
| 1 | Запись голоса в любой момент | 0 xruns, ≤30 с, сэмпл на пэде |
| 2 | Mute + LED | запись невозможна при mute; LED горит только при включении |
| 3 | Битбокс | ≥80 % попаданий в шаги на 4/4 при 90–140 BPM, классы kick/snare/hat |
| 4 | Задержка mic→P4 | ≤5 мс |
| 5 | Уровень/AGC | нет клиппинга при крике, слышно шёпот (AGC 40 дБ) |
| 6 | Приватность | нет передачи без действия; mute разрывает питание |
| 7 | Вокодер (v1.1) | разборчивость ≥80 % слов по тесту, 8 полос |

## 6. Влияние на ревизии (до заказа PCB!)

- **PANEL-2 rev.3**: MEMS I2S (ICS-43434) + акустический порт + линии I2S1/3V3/GND в J13/J14
  + опционально 3.5 мм mic jack (если на панели) — либо jack на CORE-2.
- **CORE-2 rev.3**: I2S1 RX (2 линии), 3.3 В mic power, MAX9814 + аналоговый коммутатор
  (line/mic), ESD; DFM: TP на MIC_DATA/BCK, экранирование от BL/WS2812.
- **Механика**: отверстие/сетка, клипса гусиной шеи, fitcheck + акустический тест.
- **BOM**: MEMS ~$1–2, MAX9814 ~$1, jack ~$1, сетка/поролон.

## 7. Что нельзя делать

- Не делать «always-on mic» без аппаратного mute и LED.
- Не отправлять звук по Wi-Fi/BT без явного действия пользователя.
- Не добавлять микрофон «после PCB» — это ревизия PANEL-2/CORE-2, делаем до заказа плат.
- Не обещать студийное качество: MEMS + AGC — для идей/битбокса/вокодера, не для вокала.
