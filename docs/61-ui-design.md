# UI/UX дизайн Букифона: итерации и лучшие практики

Цель: музыкант должен получать результат **быстро и без инструкции**, а интерфейс — не мешать
исполнению. Ниже — итерации, решения и правила, которые применяются в прошивке и веб-демо.

## 1. Принципы (лучшие практики синтезаторов)

| Принцип | Как реализуем |
|---|---|
| **Direct manipulation** | 16 энкодеров = 16 параметров на экране; поворот меняет звук сразу |
| **Один экран — одна задача** | страницы MAIN / FM / ENV / FX; режимы SYNTH / SAMPLER / DAW / USB-KBD |
| **Единая иерархия** | верх — глобальное (BPM/STEP/MODE), середина — рабочее (секвенсор), низ — параметры/энкодеры |
| **Никаких «прыжков»** | pickup/no-jump для энкодеров и фейдеров; значения per-mode |
| **Обратная связь** | значение под энкодером, бегунок, playhead, REC-индикатор, flash «изменено» |
| **Undo** | Ctrl+Z / кнопка: отмена последнего движения/паттерна |
| **Быстрый доступ** | фейдеры-режимы (TRACK/SCENE/DJ), mute/solo, copy/paste паттерна |
| **Цвет = смысл** | партии: green/orange/blue/purple; REC — red; accent — активный элемент; не более 5 цветов |
| **Контраст и размер** | минимум 11 px для параметров, 9 px для подписей, AA-контраст на тёмном фоне |
| **Одна рука** | дальние энкодеры достижимы без переноса локтя (проверено paperkit) |
| **Живая обратная связь без задержек** | значения обновляются на кадре, звук — на блоке ≤64 сэмплов |
| **Сохранение контекста** | сцена/паттерн/страница запоминаются; после перезагрузки — то же состояние |

## 2. Три итерации

### Итерация A — «плоская» (v1)
- 4 партии × 16 шагов, 8 параметров одной строкой.
- Плюсы: просто, видно всё сразу.
- Минусы: 8 параметров не покрывают FM/ENV/FX; нет undo; фейдеры = только громкость/delay.

### Итерация B — «страницы + сцены» (текущая в демо)
- **4 страницы** параметров (MAIN/FM/ENV/FX) на 16 энкодеров: первые 8 — страница, вторые 8 — макросы (И–П).
- **Сцены A/B** и режимы фейдеров: TRACK, SCENE (Octatrack-морфинг), DJ (equal-power), Fn = громкость.
- **Undo, copy/paste паттерна, случайный паттерн, транспозиция**, mute/solo.
- **4 темы экрана** (Night/Amber/Phosphor/Cream) — палитра фиксирована (docs/62).
- Плюсы: быстрое переключение задач, живой морфинг, «как на железе» 16 ручек.
- Минусы: нужно помнить, какая страница активна (решается индикатором page).

### Итерация C — «перформанс» (после v1.0-rc)
- Запись движения фейдера в сцену (автоматизация);
- переназначение энкодеров drag&drop (как в Elektrone: hold encoder + page);
- «macro pages» для живого выступления (4 макроса на страницу);
- лупер-страница (backlog, docs/63);
- A/B-сравнение паттернов и откат (history).

## 3. Экран: сетка 800×480

```
+--------------------------------------------------+
| BUKIFON | MODE tabs | BPM STEP PAGE THEME        | 44 px
+--------------------------------------------------+
| PART 1  [16 шагов, playhead]                      |
| PART 2  [16 шагов]                                |
| PART 3  [16 шагов]                                |
| PART 4  [16 шагов]                                |
+--------------------------------------------------+
| PAGE tabs (MAIN FM ENV FX)                        |
| 8 параметров: значение + бегунок + E1..E8         |
+--------------------------------------------------+
| MASTER meter | фейдеры-режим | подсказки          |
+--------------------------------------------------+
```

- 16 энкодеров: **8 страницы + 8 макросов** (И–П), подписи буквами как на панели.
- 42 клавиши: два кластера 3×7, наклоны ∓18°, как на реальной панели.
- Цветовые токены — docs/62; одинаковые hex в прошивке, демо и на сайте.

## 4. Чек-лист UX-ревью

- [ ] Новый экран: понятно без подсказки за ≤3 секунды?
- [ ] Все действия обратимы (undo) или подтверждаются?
- [ ] Значения не прыгают при смене режима (pickup)?
- [ ] REC/сохранение не прерывают звук?
- [ ] Контраст и размер шрифта читаются при 30 см?
- [ ] Раскладка проверена paperkit (docs/28) и демо?
- [ ] Ограничения честно показаны (SPI-экран/8×8 USB/…) до покупки?

## Локализация RU/EN (раунд 24)

Интерфейс вынесен в строковую таблицу `firmware/include/bukifon_i18n.h`
(`enum class UiKey`, RU+EN для каждого ключа) и рисуется через `tr(key)`.

- **Ключи:** 7 вкладок (MAIN/SEQ/MIX/MOD/GEN/EXT/MIC), заголовки 7 страниц,
  статусы (PLAY/STOP/REC/READY/ON/OFF/SAVED/UNSAVED/PASS/FAIL/SKIP/ERROR),
  контекст-строка (PART/SELECTED/PAGE/PAT/BAR/FADERS/MIC), поля MAIN/GEN/EXT/MIC,
  макросы И–П, подсказки, ошибки self-test. Всего **90+ ключей**, у каждого
  непустые RU и EN; EN ≤28 символов (кроме описаний — их в таблице нет).
- **Переключение:** `setLanguage(Lang::RU|EN)` / `getLanguage()`; `tr(key)`;
  host-настройка `i18nSaveLanguage()/i18nLoadLanguage()` (TODO(hw): NVS/flash).
- **Project v2:** поле `language` добавлено в заголовок `.bkfp`; старые v1
  файлы мигрируют с `language=RU`; старый v2-заголовок (214 байт) читается с
  RU по умолчанию. Загрузка не меняет глобальный язык неявно — приложение
  применяет его явно.
- **Отрисовка:** `ui800.cpp` использует `tr()` для вкладок/страниц/статусов/
  контекст-строки/полей MIC/EXT/GEN/MAIN; буферы `UiParam.label/hints` увеличены
  под UTF-8. **Кириллический glyph-пакет реализован**:
  `firmware/src/ui/font_cyrillic6x8.*` — 66 глифов 6×8 (А–Я, а–я, Ё/ё),
  UTF-8 → glyph lookup (`uiFontGlyph`), ASCII остаётся на прежней таблице.
  Транслитерация удалена: RU-строки рисуются настоящими кириллическими
  глифами (transliteration no longer used); ширина всех RU/EN ключей ≤90 px
  при ячейке 94 px (метрика `uiTextPixelWidth`, UTF-8 codepoint count).
- Скриншоты: `firmware/artifacts/ui/{synth,gen,ext,mic,main}_{ru,en}.png`
  (10 PNG, RU и EN; визуально проверены).
