## 6. Риски (честно)

- **PCB без стендов = риск respin** — не заказывать до 13/13 PASS и P1;
- P4 SDK молодой: IDF 5.5 собирает hello, но esp_lcd/TinyUSB/MEMS-драйверы ещё не проверены;
- микрофон: акустика (SNR/изоляция от BL/WS2812) проверяется только на образце;
- поставки компонентов (TPS61088, MAX17048, ICS-43434) — нужен второй источник;
- рынок контрактной сборки: цены/сроки меняются, нужен RFQ (docs/72).
